# M9 接线答复与尚缺的真实证据

## K01｜安全读取接口已接入，真实事件PIT字段仍缺

已依据最新A015答复继承并调用已验收B035 / PR46的 `perception.attribution.snapshot.m8_provider`。默认生产入口不再依赖外部手工注入。M8输入日取前一已闭市交易日，overlay仍以当天计划交易日投递；cutoff在批次入口固定。provider使用独立的REPEATABLE READ READ ONLY事务并回滚，复用M9本模块已有SHADOW连接配置，不结束主输入事务、不借管理员/其他业务账号、不新建权限。权限或连接失败明确incomplete及错误类型，不输出原数据库错误文本。

三阶段 `attribution_candidates / attribution_tracks / attribution_labels` 必须在该输入日、cutoff前以ok结束。没有事件且三阶段真实完成时，可以发布已检查的空结果；有事件时，B035明确返回现有历史机制、暴露、方向、背离等字段缺口。M9保留这些来源ID和逐字段原因，不把它们当完整事件、不造新覆盖层，继续沿用旧版本/生成时间。

**仍未解决**：实际事件日要产生可信冷静期，需M8保存带真实生成/可见时间的不可变输入快照。最新A015答复明确该M8 schema/interface追加合同须经用户授权后另派B036；A不代建上游表、不以当前可变report反推历史，不补造五日PIT证据。当前接线测试证明安全读取与降级，不能证明真实五日覆盖层已完成。
