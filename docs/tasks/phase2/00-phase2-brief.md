# 第二阶段总任务书（草案 v0.1，2026-10-31）

> **已被 `docs/phase2/phase2-plan.md`（v1.0，2026-11-01）取代，仅留作记录。**

> 用户 2026-10-31 决定：二期现在开工，与一期运行检验并行；回测与市场晴雨表两条主线并行。
> 晴雨表的结论规则等用户读完 `docs/phase2/market-barometer.md` 后再定，定之前只做数据摸底。
> 范围以 `docs/system-spec.md` §1.5 为准；本文只定分工、顺序和完成标准。

## 1. 目标

1. 回测：每条候选规则都有“比规则 A 好还是坏”的结论；至少一条收紧类规则通过并启用；高成长股买入路径有回测证据。
2. 晴雨表：每天给出钟摆位置、脆弱程度和是否需要提醒，只提示、不改交易。

## 2. 硬约束

- 回测必须调用线上同一套规则 A / 纸面执行代码（M3/M4），不另写一份；先复现 v18 回放，对不上不进入下一步。
- 只用当时已公开的数据（PIT）：按当时成员、财报按 SEC 提交日生效、行情不复权穿越。
- 没有历史的数据（一致预期 10-17 起、新闻事件、期权、财报发布时间）不做历史回测，只用前向影子评估，报告中写明。
- 启用顺序：先收紧、后放宽。每条启用都要：回测报告 + 一个季度并行影子 + 用户批准。
- 一期在运行检验期，二期任何改动不得影响一期线上进程和规则 A 结果；回测在独立 schema / 独立进程中运行。
