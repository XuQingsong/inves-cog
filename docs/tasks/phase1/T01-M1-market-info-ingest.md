## 自测报告要附的证据

- 连续 5 个交易日真实运行的 `job_runs` 和 `source_health` 导出
- 每日分钟线覆盖率；广域集合入选数和各排除原因计数
- 随机 10 条新闻的 `published_at` 与原文核对表；10 次财报发布的 `reaction_day` 与 SEC 接收时间核对表
- 按模板（模块文档 README 第 7.2 节）写 `handoff/M1/self-test.md`，逐条对应上表的验收条款

## 最容易出错的地方

- 分钟线从 04:00 开始、20:00 结束；半日市盘后从 13:00 起
- 盘后无成交时 `post_close` 是 `NULL`，不是常规收盘价
- 全量库**只存不删**：采集数 = 入库数 + 去重数
- `published_at` 和 `first_seen_at` 都要存，都用 UTC
- 财报反应日只看 8-K Item 2.02 的接收时间，不看 10-Q 申报日
