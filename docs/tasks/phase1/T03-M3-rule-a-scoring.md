## 最容易出错的地方

- 空账本是 `NULL`，不是 0；页面和接口都不能显示成 0
- 阈值开闭严格按规格符号：`dev50 = 15` 不触发 M-18
- 分层只在新财报生效那天重估
- 只能通过 `state_asof()` 取财报
