## 最容易出错的地方

- 信号日收盘生成信号，次日开盘成交；额度检查用信号日权益，成交金额用开盘权益
- 订单理由只含 `M-` 编号，不得出现任何估值区间字段
- 计划里的 `skips` 只包括文档第 4 节列出的四类
- VIX 缺失不是恐慌日
- 不能为了通过回放去改交易规则或改标准答案

## 开工第一步

写 `handoff/M4/kickoff.md`（模板见模块文档 README 第 7.1 节），以草稿 PR 提交，然后**停下等答复**。复述单除了模板要求的内容，还必须写清：

- 规格没写明、以 Muse 源码为准的执行细节（小数股、成交价取整、同日多信号的处理顺序等）
- 回放的冻结输入如何从 Muse 产出生成、如何登记

## 不要做

- 不改 `docs/` 下的任何文件，包括标准答案；
- 不导入、不调用 stock-pm 或 Muse 的代码，不读写它们的数据库；
- 不实现模块文档"不做"清单里的内容，也不顺手改其他模块；
- 文档没写的行为不自己决定，写进 `handoff/M4/questions.md` 等答复；
- 不跳过测试，不用真实 key 或网络做测试。
