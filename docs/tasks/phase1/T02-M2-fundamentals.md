## 最容易出错的地方

- `legacy` 在本项目内重写，参照 Muse 源码，不导入、不拷贝；与 Muse 冻结输出逐字段一致
- v18 复现用 `legacy`，日常纸面运行用 `fixed`
- 分部数据只从 XBRL 实例取；重分部时不跨口径算同比
- 一致预期没有历史：不回补、不外推，窗口不足写"不足 N 天"
- `op_margin_ttm` 是 M8 隐含幅度要用的字段，别漏
