# T07 · M7 异常感知

> 交给：一个开发 agent。按第一阶段任务书第 4 节的工作规则执行，完成后提交验收。

## 你的任务

每天收盘后（含盘后），不依赖任何新闻，把所有不正常的价格变化找出来：三条发现路径和多日累积、数据质量核对、合并与归层、资金放大特征、初步类型候选；北京 20:00 做一次盘前复核。本任务只回答"哪里异常、是什么形状"，不写任何原因。

## 自测报告要附的证据

- 四个案例的检测结果
- 屏蔽全部新闻源后重跑四个案例的结果
- 连续 5 个交易日的异常清单和 `job_runs` 计数
- 按模板（模块文档 README 第 7.2 节）写 `handoff/M7/self-test.md`，逐条对应上表的验收条款

## 最容易出错的地方

- 模块的输入里不能有新闻表
- 同一天同一时段命中同一组股票只算一个异常，保留全部入口
- 归层只能逐层向上
- 盘前复核不创建新的日级异常
