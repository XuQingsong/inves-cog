# M7 异常感知

| 项 | 内容 |
|---|---|
| 文档版本 | v1 |
| 规格章节 | 5（全部）、1.4（盘前复核） |
| 依赖 | M6（`marketstate`、篮子） |
| 关闭的不变量 | 无（I23 在 M8 关闭） |
| 规模 | 中 |

## 1. 目标

每天收盘后（含盘后），不依赖任何新闻，把所有"不正常的价格变化"找出来：个股、篮子、板块、大盘四个层次，一天的和几天累积的；同时描述这次变化有没有资金放大的特征。

对应需求："怎么发现股价异常"；"某些板块的股价同时异常"；"能感知股价异常，允许有延迟，以天为单位"；"很多资金行为会借消息和情绪，形成轧空或踩踏，把异常加速放大"。

## 2. 范围

**做**：三条发现路径和多日累积、数据质量核对、合并与归层、资金放大特征、异常类型的初步候选、异常对象、池外异常（广域集合）、北京 20:00 的盘前复核。

**不做**：找原因（M8）；冲击分解（M8，需要隐含幅度）；"事件冲击 / 叙事冲击"的类型判定（M8 补全）；处置卡渲染（M10）。

**边界澄清**：

- 本模块的结论只有"这里有异常、是什么形状"，**不写任何原因**。所有异常创建时状态为"已发现·原因未明"。
- 一次异常只算一个对象：同一天同一时段，三条路径命中同一组股票时合并，保留全部入口。
- 盘前复核**只**服务覆盖层：它不创建新的日级异常，只更新已有联动事件相关标的和持仓的"盘前状态"。

## 3. 输入

| 输入 | 来源 |
|---|---|
| `marketstate.daily`、`marketstate.baskets`、`marketstate.market` | M6 |
| 日线、分钟线（盘前） | M1 |

## 4. 输出

**`perception.anomalies`**：规格第 5.7 节的字段，外加：

`anomaly_id, trade_date, session(close/post), entry_paths text[](A/B/B_basket/C/multi_3d/multi_5d), layer(L1/L2/L3/L4), baskets text[], members jsonb[{ticker, ret, resid, resid_z, vol_mult}], direction, max_abs_z, data_quality jsonb, coverage jsonb, amplification jsonb, type_candidates_prelim text[], status('已发现·原因未明'), universe('pool'/'wide')`

**`perception.premarket_review`**：`trade_date, ticker, prev_close, premarket_last, premarket_ret, premarket_z, reason(holding/linked_event), flag`

## 5. 功能需求

| 编号 | 需求 |
|---|---|
| FR-M7-01 | 路径 A（总冲击）：对每个 L2、L3 篮子和本周的自动聚类组合，篮子原始等权收益 ÷ 自身 120 日收益标准差的绝对值 ≥ 3，且同号成员比例 ≥ 60% |
| FR-M7-02 | 路径 B（相对异常）：个股 `|resid_z| ≥ 3`，或个股收益与主 L3 篮子等权收益（不含本股）之差的绝对值 ≥ 4 个百分点 |
| FR-M7-03 | 路径 B（篮子）：L2、L3 篮子 `|resid_z| ≥ 3` |
| FR-M7-04 | 路径 C（因子自身异常）：SPY、QQQ、IWM、11 只行业 ETF 的日收益，VIX、2 年期美债收益率、广义美元、WTI 的日变化，相对各自 120 日标准差 `|z| ≥ 3` |
| FR-M7-05 | 多日累积：3 日和 5 日累积剩余 `|z| ≥ 3`（z 用 σ × √n），且同号天数占比 ≥ 60%；当天已经有单日异常的同一对象不重复建，合并为一个异常并加入口 `multi_*` |
| FR-M7-06 | 两个时段都算：收盘到收盘（`close`）、收盘到盘后收盘（`post`） |
| FR-M7-07 | 数据质量核对（先于判定）：（a）收益绝对值 > 30% 且当天有拆股 / 分红记录 → 先按复权价重算；（b）连续 3 天收盘价完全相同 → 标 `stale_price`，不判定；（c）盘后累计成交量 < 20 日均量的 0.5% → 标 `thin_post`，照常判定但写入 `data_quality`；（d）报价来源不一致时标"待核验" |
| FR-M7-08 | 合并：同一 `trade_date` 和 `session`，成员集合有交集、或一个是篮子而另一个是其成员 → 合并为一个异常，`entry_paths` 取并集 |
| FR-M7-09 | 归层：命中路径 C 的 L1 代理 → L1；否则 L2 篮子异常且同号成员 ≥ 60% → L2；否则 L3 篮子异常 → L3；否则 L4。只能逐层向上（规格第 3.1 节） |
| FR-M7-10 | 池外异常：广域集合只跑路径 B（因子为 SPY + 行业 ETF），结果 `universe = 'wide'`，进清单但不触发 M8 的完整归因，只做回捞和记录 |
| FR-M7-11 | 资金放大特征（每个异常一组布尔值和数值，数据不可得时为 `NULL` 并写"未接通"）：**踩踏**：成员 6 个月涨幅位于全池 + 广域前 10%；篮子 20 日平均两两相关系数较 60 日高 0.1 以上；跳空低开 ≤ −3%；成交量 ≥ 20 日均量 2 倍；同号成员 ≥ 80%。**轧空**：空头占流通股 ≥ 15% 或回补天数 ≥ 5；放量 ≥ 3 倍上涨；跳空高开 ≥ 3%。**杠杆 / 被动**：当天是指数调整日或月度期权到期日；相关杠杆 ETF 当日成交量 ≥ 20 日均量 2 倍。**情绪放大**：留空，由 M8 填写。个股隐含波动率和偏度第一阶段未接通 |
| FR-M7-12 | 初步类型候选：轧空、踩踏、主题轮动（同日一个 L3 篮子 z ≥ 3、另一个 z ≤ −3，且 SPY `|z| < 1`）、宏观 / 流动性（L1 异常且利率、美元、VIX 中至少两个 `|z| ≥ 2`）、待定；"事件冲击""叙事冲击""原因未明"由 M8 判定 |
| FR-M7-13 | 盘前复核：北京 20:00（美东 08:00），对持仓和处于"假设中 / 市场确认 / 核查中"的联动事件所涉标的，计算盘前收益和 `premarket_z = 盘前收益 ÷ 日剩余 σ`，`|z| ≥ 3` 置 `flag` |
| FR-M7-14 | 每天北京 08:15 前完成日级判定；写 `job_runs`，包括各路径命中数和数据质量拦截数 |

## 6. 异常与降级

| 情况 | 行为 |
|---|---|
| `marketstate` 当日缺失 | 不判定，系统日志标红"价格结构未更新"；不得用前一日结果 |
| 某篮子当日为空 | 该篮子不判定；成员的路径 B 照常 |
| 期权、空头数据缺失 | 对应特征为 `NULL`，写"未接通"或"数据暂缺" |
