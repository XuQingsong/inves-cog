# M5 估值 v1.1 与估值—仓位对照

| 项 | 内容 |
|---|---|

## 1. 目标

给每只标的一个稳定、可复算的估值区间（悲观 / 中性 / 乐观），告诉用户"值多少、现在贵不贵"；并把估值和规则 A 的实际仓位并排放在一起，记录"如果估值参与会怎样"，但**不改动任何一笔订单**。

对应需求："每只标的都要经过评分和估值"；"仓位和风险管理要和估值、当前价格放在一起看"；"估值可以先有一版，这一版不能去改仓位管理模块"；"看所有标的的价值"。

## 2. 范围

**做**：类型判定（8.2）、五种算法（8.4）、p 和显示档位、成长类隐含增速和 Δg（8.5）、更新触发与"待复核"、置信度（8.6）、变化分解、影子记录 V-T1 / V-T2 / V1 / V2 / V3（8.8）、估值—仓位对照的计算（8.12）、`valuation_v1` 的权限隔离。

**不做**：任何订单；分部加总估值；事件情景估值；历史评估 V-A6 和赢家案例复核 V-A7（第二阶段）；页面渲染（M10）。

**边界澄清**：

- 三档价值**只**在第 8.6 节的触发条件下重算；每天收盘只更新 p 和隐含增速。
- 估值模块读取财报用 M2 的 `state_asof(..., extractor='fixed')`，**不读** M3 的打分结果（H 规则：估值单独读原始数据）。
- 估值—仓位对照读取 M4 的持仓和计划是**只读**的（H4）；结果写在 `valuation_v1`，交易角色读不到。
- "变化分解"按固定顺序逐项替换输入（第 5 节 FR-M5-07），保证同一变化每次分解结果相同。

## 3. 输入

| 输入 | 来源 |
|---|---|
| 财报状态、年度序列 | M2 `state_asof`、`fin_state` |
| 一致预期 | M2 `consensus_snapshot` |
| 价格历史（10 年 TTM PE 分位） | M1 日线 + M2 EPS 序列 |
| 板块参数 | `config/params`：周期子行业 PE 档、未盈利成长 EV / 营收档、板块篮子（L2）成员 |
| 持仓与计划 | M4 `trading.ledger`、`trading.plan`（只读） |

## 4. 输出

**`valuation_v1.ranges`**：规格第 8.10 节"每日输出"的全部字段。

**`valuation_v1.position_panel`**：规格第 8.12 节的全部字段，每只持仓和当日计划候选一行，外加组合汇总一行。

**`valuation_v1.shadow_rules`**：每只每天一行：`vt1, vt2, v1_score, v2_coef, v3_trim_flag`，以及"与规则 A 实际的差异"描述。

## 5. 功能需求

| 编号 | 需求 |
|---|---|
| FR-M5-01 | 类型判定按规格第 8.2 节的顺序；连续两期满足新类型才切换；人工指定留痕 |
| FR-M5-02 | 五种算法按规格第 8.4 节；`golden/m5_valuation_synthetic.json` 全部用例命中 |
| FR-M5-03 | 顺序约束、p、显示档位、Δg 和档位文字按第 8.5 节；隐含增速用二分法在 g ∈ [−50, 200] 内反解，区间内无解时为 `NULL` 并标"无法反解" |
| FR-M5-04 | 倍数分位：过去 10 年每日 TTM PE（EPS > 0 的日子），去掉最高和最低各 2.5%，用线性插值取分位；不足 5 年用 L2 板块成员 P50 的中位数，置信度降一档 |
| FR-M5-05 | 更新触发和"待复核"按第 8.6 节；一致预期失效时退回 TTM 口径并标注 |
| FR-M5-06 | 置信度按第 8.6 节逐条降档；未盈利成长类最高为"中" |
| FR-M5-07 | 变化分解：按"类型 / 方法 → 一致预期输入 → 财报输入 → 倍数分位"的顺序逐项替换新值并记录中性值的增量；类型或方法变化时全部增量计入"类型 / 方法"；各项之和等于中性值总变化 |
| FR-M5-08 | 影子规则 V-T1、V-T2、V1、V2、V3 按第 8.8 节逐日计算并记录，不产生任何订单 |
| FR-M5-09 | 估值—仓位对照按第 8.12 节；`golden/m5_valuation_synthetic.json` 的 `valuation_position_panel` 全部命中 |
| FR-M5-10 | 每个对外输出（JSON、页面数据）都带固定句子"估值参考 v1，不参与仓位"（I21） |
| FR-M5-11 | 权限：`role_trading` 对 `valuation_v1` 无 SELECT（I20）；交易模块不导入估值模块（I01 已在 M0） |
| FR-M5-12 | 每天收盘后（北京 10:30 那一轮）运行；写 `job_runs` |

## 6. 异常与降级

| 情况 | 行为 |
|---|---|
| 某只计算抛错 | 该行写 `status = failed` 和错误摘要；其他标的继续；交易不受影响 |
| 中性值无新财报变化 > 25% | 新值标"待复核"，新旧并列，不替换 |
| 类型为"困境（不估）" | 三档为空，显示"不估值：亏损且无增长" |
| 外国申报人 | 年度口径，置信度低 |
