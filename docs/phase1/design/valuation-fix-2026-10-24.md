# 估值模型修正方案（2026-10-24，需求方）

## 1. 现状：59 只里 38 只结果不可用

2026-10-22 生产 `valuation_v1.ranges`：49 只有结果、10 只未估值（结果写 0）。以“中性价 / 现价”不在 0.5–2 倍或为 0 判为不可用：**38 / 59**。

| 股票 | 类型 | 现价 | 模型中性价 | 问题 |
|---|---|---:|---:|---|
| NVDA | 成长 | 212 | 538 | 用过去 3 年营收复合增速（110%，封顶 60%）外推未来 3 年 EPS |
| AMD | 成长 | 508 | 91 | 用 GAAP TTM EPS 3.89（被并购摊销压低），历史增速 23.6% |
| MU | 周期 | 856 | 219 | 周期股用中周期利润，处在景气高点时价格与之脱节 |
| STX / WDC | 周期 | 642 / 354 | 60 / 6.7 | 同上，且利润刚由亏转盈 |
| ADBE / CRM / AMZN | 稳定 | 271 / 250 / 250 | 959 / 1278 / 613 | 历史 PE 中位数偏高时直接套用 |
| AVGO / GE / JPM 等 10 只 | — | — | 0 | 未估值却写 0，页面会误读为“值 0 元” |

## 2. 根因

1. **只看过去**：成长股增速取历史营收/EPS 复合增速，周期股取中周期利润，**没有前瞻利润**（`eps_ntm` 全为空，系统没有一致预期数据源）。
2. **口径问题**：GAAP EPS 含一次性和摊销（AMD、并购型公司失真）。
3. **历史估值倍数直接套用**：稳定股用本股十年 PE 中位数，对估值中枢已变化的公司不成立。
4. **失败写 0**：未估值应为空并说明原因。

## 3. 已验证可用的数据

- 模型已能算**现价隐含增速**（反解：现价意味着未来 3 年 EPS 年增多少）：NVDA 27.7%、AMD 95.6%、MSFT 25.3%、PLTR 115.9%、LLY 29.6%。这是有意义且不依赖外推的信息。
- **Alpha Vantage `EARNINGS_ESTIMATES` 可用**（现有 key，2026-10-24 实测 200）：NVDA 分析师一致预期 FY2027 EPS 9.31（51 家）、FY2028 15.91（52 家）→ 现价对应前瞻 PE 22.8 倍 / 13.3 倍。免费额度每日 25 次，59 只需约 3 天轮一遍；一致预期是当前快照，需每日存档才能做 PIT。

## 4. 方案

**阶段 A（立即，页面层，随 B-053）**
- 不展示不可用的“合理价”；未估值显示“未估值（原因）”，不显示 0。
- 每只改为展示三件事：当前 PE 与本股历史分位；**现价隐含增速 vs 过去 3 年实际增速**（“市场在押注什么”）；有一致预期时显示前瞻 PE。
- 文案示例：“NVDA 现价隐含未来 3 年 EPS 年增约 28%，过去 3 年实际约 110%；按分析师预期，前瞻市盈率约 23 倍（明年）/ 13 倍（后年）。”

**阶段 B（数据源，需用户决定）**
- 接入 Alpha Vantage 一致预期，每日存档（新表或 M1 信息表扩展）；免费额度轮询 59 只（约 3 天一轮），或升级付费额度每日全量。

**阶段 C（方法修订，阶段 B 后）**
- 成长股：用一致预期 EPS（FY1/FY2）替代历史外推；增速取一致预期与历史的较小值并封顶。
- 周期股：标注景气位置（当前利润 / 中周期利润），高景气时给“若回到中周期利润”的下行参考，而不是给中性价。
- 稳定股：PE 中枢改为“历史分位 + 同行业当前分位”的组合。
- 保留现有 PIT、反解、三档结构；`method_version` 升级为 v2，与 v1 并行一段时间对比。
