# 投资者页面 · 交互原型 v1（定稿）

`index.html` 是单文件交互原型，双击即可打开，不依赖网络。数据来自线上 2026-10-22 的页面。B 实现时**照此一比一还原**：服务端渲染 HTML，交互部分用原生 JS。

入口（hash 路由）：`#market`、`#stocks`、`#account`、`#account/AVGO`（直接定位并展开某只持仓）、`#trust`、`#s/AVGO`、`#s/LITE`、`#ds`（设计系统）。

这份原型取代 C-001 的 Figma 稿和 PR #78 的修订预览：C 线 Figma 额度用尽后，由协调人按复核一、复核二的全部意见完成定稿。

## 定稿规则（实现必须遵守）
1. **颜色只表达一件事**：涨跌色只用在数字文字上；风险等级用图标 + 底色标签表示（`!` 重点下行、`▲` 下行关注）；止盈提示用蓝灰色 `↗`，不计入风险数。导航徽标、页面标题、"对我意味着什么"里的计数只统计下行风险。
2. **价格尺**：只画该持仓类型适用的价位。
   - 核心仓另画 200 日线虚线作参考，观察波段仓不画；
   - 实线着色段 = 现价到最近一个未触发价位的距离；
   - 没有价格触发线的核心仓（标准层、防守层）改用虚线段，标注"已低于 200 日线 X%"或"再跌 X% 跌破 200 日线"：已跌破或距离小于 10% 时用橙色，否则用灰色；
   - 已越过的触发价画成空心圆并加 ✓；
   - 标签按六条泳道（上 3、下 3）自动避让，CJK 字宽按字号、拉丁字符按 0.61 倍字号估算。
3. **规则的四种状态**：未到门槛、已到门槛 · 待执行、已到门槛 · 暂不执行、已执行 · 不再重复。每种状态有独立的左边框色和底色。附加条件逐条用 ✓ / ✗ 列出。
4. **原位展开**：点击持仓行，在该行下方展开条件卡片；点击风险项或待成交行时，先定位到对应持仓，再展开并高亮 1.4 秒。
5. **状态**：计划缺失日沿用前一日持仓，并在顶部提示（原型里点 › 切到 10-23 查看）；盘中模式标注"截至 HH:MM ET · 延迟约 16 分钟"，并说明不进入规则 A；暂缺、过期、旧闻、部分覆盖都有固定样式。不画虚构走势，例如指数近 20 日走势在原型中标为"待接入"。
6. 禁止出现：下单按钮、"实时"字样、目标价或合理价、内部编号（M4、N1、basket 代码、英文字段名）。

## 数据口径修正（B 实现时一并处理）
| 问题 | 要求 |
|---|---|
| 账户页"距高点"为 −3.27%，而回撤刹车距离按 −3.65% 计算 | 两者都用**按收盘估算的总资产 / 历史峰值 − 1**（`risk_brief` 的口径），即 −3.65% |
| 10-23 计划缺失时，账户页显示空仓 | 沿用最近一次有效持仓，并显示"计划缺失"提示 |
| 风险分组 | 止盈接近（翻倍价已到、波段止盈接近）移到"止盈提示"组；当日跌幅 ≥ 5% 或卷入当日异常，按现有规则仍算下行风险（AMD 同时出现在两组） |
| 待成交单缺数量 | 从账本取股数；取不到时显示"暂缺" |
| 处置记录 | 区分"计划"和"已成交 · 价格 · 股数"；AMD 10-21 的两条重复记录要确认是否重复 |
| 待选股票缺现价 | 增加现价列（原型里的现价由一年高点和距高点百分比反推，实现时直接取收盘价） |
| 空头结算日晚于页面日期（PLTR 11/15、WMT 11/28） | 排查是否误用了未来数据；页面不得展示晚于截点的数据 |
| 极端市盈率（CRWD 4,758.8、PANW 887.3） | 超过合理阈值时显示"市盈率不适用"；PANW 的"无法反解：价格不在[-50,200]…"这类内部文字要翻译成人话 |
| HD 不在 59 只标的池内 | 当日涨跌显示"暂缺"即可，或单独取 HD 的日线 |

## 原型里的数据说明
- 持仓、价位、条件、风险项都摘自线上 10-22 的 `/account`；个股走势用线上 sparkline 的坐标反推价格，只作示意。
- "发现的数据异常"区块是新增的组件，实现时由数据质量检查生成；原型里的三条是本次走查发现的真实问题。
