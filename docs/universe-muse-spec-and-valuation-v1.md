## 2. 标的池：板块 × 龙头

### 2.1 原则

- 不追求数量。每个板块 3–5 只龙头，板块之间要能**互相解释联动**（存储 ↔ AI 服务器 ↔ 电力 ↔ 云厂商）。
- 新增板块优先服务于已讨论过的案例：东芝 → HDD、OpenAI ARR → AI 资本开支链、Meta Muse → CPU。
- 龙头的标准：子行业市值前列、20 日均成交额 ≥ 2 亿美元、在 SEC 按 10-Q / 10-K 申报（外国申报人见 2.4）。
- 广域日线（约 1000–1500 只）**保持不变**，继续负责"池外异常"的发现；池子只决定谁有完整的打分、估值和交易资格。

## 3. Muse 方法规格（重写依据）

这一节把 Muse v18 的全部规则写成与语言无关的规格。重写时**只认这一节**，不参考 Muse 原代码的结构。规格编号 `M-xx`，便于在代码和测试里引用。

### 3.1 总原则

- **M-01 机械化**：从当前价格出发，按打分和规则决定能不能买、买多少、何时卖；**不设目标价**。
- **M-02 PIT**：任何一天的计算只用当天收盘时已经公开的数据。财报按 SEC **申报日**（`filed`）可见，Form 4 按申报日可见。
- **M-03 时序**：信号在收盘后生成，**次日开盘价**成交；同一天先执行卖单、后执行买单。
- **M-04 成本**：每笔成交 0.1%（买入加价、卖出减价）。
- **M-05 最小订单**：成交金额低于当时权益的 0.5% 不下单。
- **M-06 研究性质**：纸面组合，不接券商下单（沿用 Muse 文档的约束：网页只读、不下单）。

### 3.2 输入数据

**日线技术字段**（每只股票每天计算一次）：

| 字段 | 定义 |
|---|---|
| `price` | 收盘价 |
| `price_vs_ma200` | 收盘价 / 200 日均线 − 1，单位 % |
| `ma50_vs_ma200` | 50 日均线 / 200 日均线 − 1，% |
| `ma200_slope20` | 200 日均线 / 20 个交易日前的 200 日均线 − 1，% |
| `mom3`、`mom6` | 相对 63、126 个交易日前的涨跌幅，% |
| `rsi` | 14 日 RSI |
| `dev50` | 收盘价 / 50 日均线 − 1，% |
| `vol_ratio` | 20 日平均成交量 / 60 日平均成交量 |
| `up_share` | 近 60 日"收盘 ≥ 开盘"那些天的成交量占比，% |
| `vol20` | 20 日收益率标准差 × √252 × 100 |
| `vol60` | 60 日收益率标准差 × √252 × 100（只用于分层） |
| `drawdown252` | 收盘价 / 252 日最高收盘价 − 1，% |

200 日均线不足的日子不出信号。

**财报字段**（每次有新的 10-Q / 10-K / 20-F / 6-K 申报时更新一次，状态从申报日起生效）：

| 字段 | 定义 |
|---|---|
| `rev_ttm`、`ni_ttm` | 最近 4 个季度营收、净利润之和 |
| `rev_growth` | TTM 营收同比，% |
| `rev_q_yoy` | 最近一个季度营收同比，% |
| `rev_accel_pp` | `rev_q_yoy` − 上一季度的 `rev_q_yoy`，百分点 |
| `eps_ttm` | 最近 4 个季度稀释 EPS 之和 |
| `eps_growth` | TTM EPS 同比，%；本期或上期 EPS ≤ 0 时为空 |
| `gross_margin` | TTM 毛利 / TTM 营收，% |
| `gross_margin_change_pp` | 本期 TTM 毛利率 − 一年前 TTM 毛利率，百分点 |
| `fcf_ttm` | TTM 经营现金流 − TTM 资本开支 |
| `fcf_margin` | `fcf_ttm` / `rev_ttm`，% |
| `fcf_conversion` | `fcf_ttm` / `ni_ttm` |
| `roe` | `ni_ttm` / 股东权益，% |
| `cash`、`debt`、`net_debt` | 现金、有息负债、两者之差 |
| `net_debt_fcf` | `net_debt` / `fcf_ttm`（`fcf_ttm` > 0 时） |
| `current_ratio` | 流动资产 / 流动负债 |
| `shares` | 最近申报的稀释股本 |

**每日按价格派生**：`pe = price / eps_ttm`（EPS > 0）；`mktcap = shares × price`；`ps = mktcap / rev_ttm`；`fcf_yield = fcf_ttm / mktcap × 100`；`peg = pe / rev_growth`（增速 > 0）。

**采集要求**：原 Muse 采集有标签遗漏、第四财季推算缺失、companyfacts 滞后等缺陷，重写时必须按 [`trading-rules-a-plus-and-growth-stocks.md`](trading-rules-a-plus-and-growth-stocks.md) 第 6 节的 D1–D6 实现（复现 v18 时先关闭，单独报告影响）。

**数据质量标记**：

- **M-07 财报过期**：最近营收期间的结束日距当天超过 180 天 → 质量、成长、估值三本账全部置空（不能入场，见 M-30）。
- **M-08 拆股疑似**：（PE < 5 且 PS < 2）或（PS < 3 且毛利率 > 60%）→ 估值账置空，只用其余三本账。

**其他输入**：SPY 日线（黑天鹅）、VIX 日线（恐慌闸门）、Form 4 公开市场买入（代码 P，区分高管 / 其他内部人）。

### 3.3 打分方法

- **M-10 分段线性**：每个因子按"断点表"线性插值成 0–100 分，超出两端取端点值。
- **M-11 缺项重配权**：某个因子缺数据就跳过，账本分 = 可用因子的加权平均（按可用权重归一）；全部缺失则账本为空。

| 入场位置 | 20 | `dev50`（−15→25、−8→45、−3→75、0→85、3→80、8→55、15→25、25→5）；`rsi`（20→35、30→55、45→75、60→70、70→45、80→18、90→5） |
| 波动 / 回撤风险 | 10 | `vol20`（20→90、35→70、50→50、70→25、100→5）；`drawdown252`（−60→20、−40→35、−25→50、−10→70、0→85） |

**M-12 综合排名分** = 质量 × 25 + 成长 × 32.5 + 估值 × 25 + 时机 × 17.5，再除以 100；任一账本为空则无排名分。权重固定，不按行业变化。

### 3.5 红线

| 编号 | 条件 | 标签 | 后果 |
|---|---|---|---|
| M-13 | `price_vs_ma200` < 0 且 `ma50_vs_ma200` < 0 且 `mom6` < −10 | 趋势破位 | 排除 |
| M-14 | `fcf_ttm` < 0 且 `rev_growth` < 0 | 现金流为负且营收下滑 | 排除；属于逻辑死亡 |
| M-15 | `rev_growth` < −5 且 `eps_growth` < −20 | 营收与 EPS 同时明显下滑 | 排除；属于逻辑死亡 |
| M-16 | `current_ratio` < 0.8 | 流动性偏紧 | 只观察（**不**算逻辑死亡；保险、公用事业结构性低于 1） |
| M-17 | PE > 80 且（`rev_growth` < 15 或 `rev_accel_pp` < −10） | 高估值与增长不匹配 | 等价格 |
| M-18 | `rsi` > 80 且 `dev50` > 15 | 短线过热 | 不追高 |

"排除"阻止入场；"不追高"阻止新开仓和加仓；"只观察"和"等价格"在 v18 里**只是标签，不阻止入场**（见 3.13 E5）。

### 3.6 分层

- **M-20 分层只在新财报状态生效那天重估**（以及股票首次出现时），平时不变，避免层级天天跳。波动用 `vol60`（缺失时用 `vol20`）。
- **M-21 进攻层**：`vol60` > 55，或未盈利（`ni_ttm` < 0 且 `fcf_ttm` < 0），或（`rev_growth` > 35 且估值账 < 45）。
- **M-22 防守层**：`vol60` < 30 且 `fcf_ttm` > 0 且 `fcf_margin` > 5 且质量 ≥ 70 且成长 ≥ 45 且（`rev_growth` ≥ 0 或为空）。
- **M-23 普通层**：其余。质量或成长为空时不分层（不能交易）。

| 参数 | 防守 | 普通 | 进攻 |
|---|---|---|---|
| 层预算（占总权益，只限制买入） | 30% | 30% | 40% |
| 层预算缓冲 | ×1.25 | ×1.25 | ×1.25 |
| 单票目标上限 `cap` | 12% | 12% | 8% |
| 默认首笔比例 | 50% | 40% | 30% |
| 最多持有只数 | 4 | 6 | 6 |
| 全组合最多持有只数 | 12 | 12 | 12 |

- **M-24 买入额度**：某层可买上限 = 层预算 × 1.25 × 权益。普通层和防守层在全组合投入比例 < 85% 时，可以额外借用进攻层未用额度的 75%。层内市值涨过上限**不强制减仓**，只是不再加新钱。

### 3.7 资格指标

**M-25 成长确定性**（高 / 中 / 低），按点数累加：

- 成长账 ≥ 85 记 2 点，≥ 72 记 1 点；
- `rev_growth` ≥ 30 记 2 点，≥ 18 记 1 点；
- `rev_accel_pp` ≥ 3 记 +1，≤ −8 记 −1；
- `eps_growth` ≥ 20 记 +1，< 0 记 −1；
- 总点数 ≥ 4 为高，≥ 2 为中，其余为低。

**M-26 基本面持有资格分**（0–100，只看基本面趋势和现金质量，不看价格；字段缺失时给括号里的保底分）：

| 项 | 满分 | 分档 |
|---|---|---|
| 季度营收同比 | 15 | ≥ 20→15，≥ 10→12，≥ 0→8，≥ −5→4，否则 0（缺失 8） |
| 营收加速度 | 15 | ≥ 0→15，≥ −10→10，≥ −20→5，否则 0（缺失 0） |
| 毛利率变化 | 15 | ≥ 0→15，≥ −3→10，≥ −6→5，否则 0（缺失 8） |
| 现金流 / 净利润 | 20 | ≥ 1→20，≥ 0.5→15，≥ 0→8，否则 0（缺失 8） |
| 净负债 / 自由现金流 | 15 | ≤ 0→15，≤ 3→12，≤ 5→8，否则 0（缺失 8） |
| 流动比率 | 10 | ≥ 1.5→10，≥ 1→7，≥ 0.8→4，否则 0（缺失 5） |

- `hold_ok`：资格分 ≥ 55。
- `fund_bad`：资格分 < 40，或（季度营收同比 < 0 且毛利率变化 < 0 且现金流 / 净利润 < 0.3 或缺失）。

**M-27 现金跑道**：`fcf_ttm` ≥ 0（或缺失）视为够；否则要求 `cash` ≥ 1.0 × |`fcf_ttm`|。

### 3.8 入场

**M-30 入场门槛**（按层，四本账全部达到才算过线）：

| 账本 | 防守 | 普通 | 进攻 |
|---|---|---|---|
| 公司质量 | 70 | 60 | 50 |
| 成长与预期 | 45 | 55 | 70 |
| 估值 | 50 | 45 | 30 |
| 入场时机 | 50 | 55 | 50 |

- **M-31 进攻层估值修正**：进攻层且成长 ≥ 70 时，用修正后的估值分比较门槛：`min(65, 估值 + max(0, min(20, (rev_growth − 15) / 3)))`。只用于入场判断，不改原始估值账。
- **M-32 进攻层烧钱保护**：进攻层且 `fcf_ttm` < 0 时，额外要求 `rev_growth` ≥ 30 且 `cash` ≥ 1.5 × |`fcf_ttm`|。
- **M-33 `entry_pass`** = 门槛过线 且 M-32 满足 且 没有"排除"类红线。
- 连续过线天数 `consec_pass` 每天累计，不过线归零。

**M-34 新开仓候选**（每天收盘后）：

1. 主候选：`entry_pass`，没有"不追高"，资格分 ≥ 45，有分层，未持有，当天没有挂单，距上次清仓 ≥ 10 个交易日。按排名分从高到低排序。
2. 回补候选：上次是"价格型"退出（见 3.10）；`hold_ok`；普通或进攻层；`dev50` > 0；时机 ≥ 50；估值 ≥ 该层门槛 − 10；距上次清仓 ≥ 10 个交易日。排序分 = 排名分 − 3。
3. **进攻层候选排在最前**，然后是其他层；各组内按排序分降序。
4. 逐个检查：该层只数未满、全组合（持仓 + 当天新买挂单）< 12 只；防守层的主候选还要求资格分 ≥ 55；组合回撤刹车（M-62）生效时只允许防守层。

**M-35 首笔比例**：

- 基础 = 该层默认首笔比例；
- 成长确定性高：`min(0.75, 基础 + 0.20)`；中：`min(0.65, 基础 + 0.08)`；低：`max(0.20, 基础 − 0.08)`；
- 回补候选：× 0.8；
- 全组合投入比例 < 55% 且确定性不是低：`min(0.80, 比例 + 0.10)`；
- **M-36 内部人加成**（只对主候选）：信号日前 90 个自然日内有 Form 4 公开市场买入（按申报日），高管 × 1.35、其他内部人 × 1.20，上限 0.80；
- 首笔金额 = 首笔比例 × 该层 `cap` × 权益：额度检查用信号日收盘权益（超出该层买入额度 M-24，含当天已计划的买入，则跳过），实际成交金额按次日开盘时的权益计算；
- **M-37 追高减半**：`dev50` > 15 时，这一笔的金额减半。

### 3.9 加仓（优先于新开仓）

**M-40 分级加仓**，对已持有的股票，要求 `entry_pass`、有分层、当天没卖、没有"不追高"、非 `fund_bad`、距上次卖出 ≥ 10 个交易日、该层还有买入额度；组合回撤刹车生效时只允许防守层。

- 已投比例 = 持仓市值占"该层 `cap` × 权益"的比例（按成交时累计记录）。
- **确认加仓**：已投比例 < 首笔比例 + 0.30 时，满足任一条件 → 加到 `min(0.85, 首笔比例 + 0.30)`：
  - 持有天数 ≥ N 且连续过线天数 ≥ N，其中 N = 3（确定性高或全组合投入 < 60%）否则 5；
  - 回踩：|`dev50`| ≤ 3 且 `price_vs_ma200` > 0。
- **确认补满**：已投比例 < 1 时，满足任一条件 → 加到 1.0：
  - 入场后出现了新一期财报；
  - 持有 ≥ 15 天且连续过线 ≥ 10 天。
- 加仓金额 = 目标比例 × `cap` × 开盘时权益 − 当前市值；同样适用 M-37 追高减半。

### 3.10 卖出（按优先级，命中一条后当天不再检查后面的）

退出类型：基本面退出、价格型退出。只影响回补资格（M-34）。

| 编号 | 规则 | 条件 | 动作 |
|---|---|---|---|
| M-50 | 逻辑死亡 | 命中 M-14 或 M-15；或质量 < 50（防守层）/ < 45（其他）；或成长 < 35（防守层）/ < 40（其他）；进攻层另加 `rev_growth` < 0 或现金跑道不够；或 `fund_bad` | 全部卖出（基本面退出） |
| M-51 | 进攻层灾难止损 | 进攻层，价格 ≤ 持仓期最高收盘价 × 0.60，且 `price_vs_ma200` < 0 | 全部卖出（价格型） |
| M-52 | 纯波段仓规则 | 见 3.11 | —— |
| M-53 | 核心仓上的波段仓止盈 | 持有波段股数 > 0，`dev50` ≥ 阈值；阈值进攻层 = `clamp(0.40 × vol20, 10, 18)`，其他 = `clamp(0.32 × vol20, 8, 14)` | 卖出波段股数，核心仓不动 |
| M-54 | 进攻层翻倍锁利 | 进攻层，价格 ≥ 2 × 持仓均价，且（`dev50` < 3 或时机 < 55），距上次卖出 ≥ 20 天，当前不在减仓阶段 | 卖 25% |
| M-55 | 破位减仓 | 见下表；持有 ≥ 10 天；减仓阶段 < 2；**非恐慌日** | 按下表比例卖出，阶段置 2 |
| M-56 | 警戒减仓（只限普通层） | 入场后出现新财报，且（质量 < 55 或成长 < 50），且 `dev50` < 0；阶段 = 0；**非恐慌日** | 卖 25%，阶段置 1 |
| M-57 | 解除减仓阶段 | 阶段 > 0 时，不再警戒且 `price_vs_ma200` > 0 且 `entry_pass`，连续满足 K 天（防守 / 进攻 5 天，普通 3 天） | 阶段归 0 |

**破位条件**（M-55）：

| 层 | 破位条件 | 减仓比例 |
|---|---|---|
| 防守 | 连续 10 天收在 200 日线下 | 1/3 |
| 普通 | 命中趋势破位红线，或连续 3 天在 200 日线下，或时机 < 35 连续 3 天 | 1/2 |
| 进攻 | 连续 7 天在 200 日线下，或时机 < 30 连续 5 天 | 1/3 |

**M-59 只观察不卖**：分数回落、仓位失衡、层市值超预算，都**不是**卖出理由。只有逻辑死亡，或"新财报走弱 + 趋势跌破"才减仓。

**M-59 冷却期**：任何卖出后 10 个交易日内，不对同一只股票加仓或新开。

### 3.11 波段层

- **M-60 弱势带**：回撤阈值 `dip_dd = clamp(0.55 × vol20, 10, 22)`；偏离阈值 `dip_dev = −clamp(0.18 × vol20, 3, 7)`。进入弱势带 = `drawdown252` ≤ −`dip_dd` 且 `dev50` ≤ `dip_dev`。
- **核心仓波段买入**：已持有、`hold_ok`、非 `fund_bad`、阶段 = 0、波段笔数 < 2、距上次波段 ≥ 10 天、进入弱势带且 `price_vs_ma200` > −8；金额 = 0.20 × `cap` × 权益，不能超过单票 `cap` 和该层额度。止盈按 M-53。
- **观察名单波段（未持仓）**：
  - 防守 / 普通层；进攻层另要求资格分 ≥ 65、`vol20` ≤ 60、现金跑道够；
  - 资格分 ≥ 60；`rev_accel_pp` ≥ −10（加速度明显恶化不接）；同时最多 3 个观察波段仓；距上次清仓 ≥ 10 天；
  - 进入弱势带，并且**已止跌**：5 日涨跌 ≥ −2% 且价格 ≥ 10 日最低价 × 1.03；
  - 深跌（`drawdown252` ≤ −35）需要**两次确认**：第一次止跌只记录日期和价格；5–15 天内再次满足、且价格不低于第一次的 97%，才买；
  - 金额：普通 / 防守 4%，深跌（`price_vs_ma200` < −8）2.5%；进攻层 3%，深跌 2%（占权益）；单票上限：进攻 6%、其他 8%；
  - 站回 50 日线后（距上次波段 ≥ 5 天）补第二笔到单票上限；
  - 止盈：`dev50` ≥ `clamp(0.32 × vol20, 8, 14)` 全部卖出；止损：价格 ≤ 买入均价 × 0.82 全部卖出（价格型）；基本面恶化全部卖出；
  - 纯波段仓不适用 M-54 到 M-57；
  - 一旦该股 `entry_pass`，纯波段仓转为核心仓，已投比例按当前市值折算、上限 0.6。
- 组合回撤 −12% 状态下（M-62），两类波段买入也只允许防守层。

### 3.12 组合风控

- **M-61 黑天鹅**：SPY 单日 ≤ −4% 或 5 日 ≤ −8%（与上次触发间隔超过 10 个交易日才重新触发）→ 之后 3 个交易日暂停所有买入；进攻层持仓各卖 50%（恐慌日不卖）。
- **M-62 回撤刹车**：权益较历史高点回撤 ≤ −8%（非恐慌日、且未处于已触发状态）→ 进攻层持仓各卖 1/3；回撤回到 −4% 以内解除。回撤 ≤ −12% → 只允许买防守层，直到回撤收窄到 −6% 以内。
- **M-63 VIX 恐慌闸门**：VIX ≥ 其过去 252 个交易日的 90 分位（至少 120 天数据）的日子为恐慌日。恐慌日不生成价格型和恐慌型卖出（M-55、M-56、M-61 的减仓、M-62 的 −8% 减仓）。**不受闸门影响**：逻辑死亡（M-50）、灾难止损（M-51）、波段止盈止损。已知风险：样本里没有 2022 年式的阴跌，阴跌市里闸门会让卖出变迟，页面要明示。

### 3.14 两套卖出规则（E2 的说明）

Muse 仓库里其实有**两套不同的卖出规则**：

| | A：v18 回测（`paper_trade_v18_full30.py`） | B：前向纸面跟踪（`paper_tracker.py`，10 月起每天在跑） |
|---|---|---|
| 核心思路 | 看**基本面和趋势**：基本面没坏、趋势没破就拿着 | 看**成本价的固定百分比** |
| 止损 | 没有固定止损。逻辑死亡清仓；跌破 200 日线若干天分批减仓（防守 10 天减 1/3，普通 3 天减 1/2，进攻 7 天减 1/3）；只有进攻层有"高点回撤 40% 且破 200 日线"的灾难止损 | 按层固定：防守 −8%、普通 −12%、进攻 −18%，**碰到就全部卖出** |
| 止盈 | 没有固定止盈。只有波段仓在偏离 50 日线过大时卖出，进攻层翻倍后锁 25% | 按层固定：防守 +15%、普通 +20%、进攻 +25%，**碰到卖 1/3，只卖一次**，剩下的不再止盈 |
| 触发时点 | 收盘后判断，次日开盘成交 | 盘中按 1 分钟线，碰到价线即成交 |
| 恐慌日 | VIX 闸门暂停价格型卖出 | 无闸门 |
| 结果依据 | +49.45% / −12.64% 就是这套规则跑出来的 | 没有回测，只有 10 月以来的前向记录 |

**同一只股票在两套规则下的不同结果**（示意）：普通层股票，成本 100 美元，之后先跌到 87、再涨到 125。

- **规则 A**：跌到 87 时基本面没坏、还在 200 日线上方，**不卖**；如果跌进弱势带还可能加一笔波段仓。涨到 125 时核心仓继续持有，波段仓在偏离 50 日线过大时卖出。
- **规则 B**：跌到 88（−12%）盘中触发止损，**全部卖出**，后面的反弹完全错过。如果没跌到 88，涨到 120 时卖出 1/3，剩下的 2/3 不再有止盈。

两者的取舍：

- A 能拿住正常波动里的好公司，这是 v18 收益的主要来源；代价是在"基本面还没体现、价格先走坏"的阶段卖得慢。
- B 对单笔亏损的控制更直接、更容易理解；代价是在高波动的成长股上容易被正常回调洗出去，而且没有回测证明它更好。

**问题在于**：现在 Muse 的回测成绩是 A 跑出来的，每天的纸面组合却按 B 在运行。两者的成绩不能互相印证；如果把 v18 的 +49% 当作纸面组合的预期，会误导判断。

**建议**：重写后统一按 A 执行（本规格第 3.10 节）。B 不丢掉，把"固定止损"作为一个规则变更提案，用同一套数据回测"A 加上固定止损"与"纯 A"的对比，结果更好再并入。现有 B 的前向记录保留，作为历史存档。

### 3.15 重写验收

## 4. 估值 v1（只读、只展示，不影响仓位）

### 4.1 定位

- 回答一个问题：**按固定方法，这只股票现在大概值多少、当前价格在区间里的什么位置。**
- 输出悲观 / 中性 / 乐观三档每股价值，和位置 p。
- 不使用 LLM 假设、不使用研究观点、不随新闻和价格异动调整（事件情景留到 v2）。
- **不参与任何交易决策**（4.8）。

### 4.2 类型判定

每次新财报生效时判定；类型变化需要**连续两期**满足新类型才切换；允许人工指定，留痕并注明理由。

| 顺序 | 类型 | 条件 | 第一阶段预计归类（示意，以规则计算为准） |
|---|---|---|---|
| 1 | 金融 | 银行、保险、券商（SIC 6000–6411 中的银行、券商、保险代码）。V、MA 是支付网络，不算金融 | JPM |
| 2 | 未盈利成长 | `ni_ttm` ≤ 0（或 `fcf_ttm` ≤ 0 且营业利润率 < 5%），且 `rev_growth` ≥ 15% | CRWV、BE；GAAP 净利润仍为负的网络安全公司（ZS 等，以财报为准） |
| 2b | 困境（不估） | 未盈利且 `rev_growth` < 15% | INTC（若仍亏损）；页面显示"不估值：亏损且无增长" |
| 3 | 周期 | 属于周期子行业（存储、半导体设备、能源、机械），或近 10 年至少 2 年 EPS 同比下滑超过 50% 且毛利率波动范围 ≥ 15 个百分点 | MU、SKHY、WDC、STX、SNDK、AMAT、LRCX、KLAC、ASML、XOM、CVX、CAT |
| 4 | 成长 | 3 年营收复合增速 ≥ 15%，且（一致预期次年 EPS 增速 ≥ 15% 或 `rev_growth` ≥ 15%） | NVDA、AVGO、AMD、MRVL、PLTR、META、NFLX、ANET、VRT、GEV、LLY、NOW、COHR、CEG、PANW、CRWD（若 GAAP 盈利）等 |
| 5 | 稳定 | 其余 | AAPL、MSFT、COST、WMT、HD、JNJ、V、MA、ETN、QCOM、DELL、FTNT 等 |

### 4.3 公共输入

| 输入 | 来源 | 说明 |
|---|---|---|
| TTM 财务 | 第 3.2 节的财报字段 | 与交易模块共用采集，但估值模块**单独读取原始数据**，不读交易模块的计算结果 |
| 一致预期 | 每日快照：未来 12 个月 EPS（`eps_ntm`，由当年和次年 EPS 按剩余月份加权）、次年 EPS 增速、未来 12 个月营收 | 缺失时降级（4.6） |
| 本股倍数历史 | 过去 10 年每日 TTM PE（只取 EPS > 0 的日子），去掉最高和最低各 2.5% 后取分位 | 不足 5 年时用板块篮子的中位数 |
| 年度序列 | 近 10 个财年营收、净利润率、EPS | 周期类用 |
| 股本 | 稀释股本 | 未盈利成长类悲观档额外加 5% 稀释 |

### 4.4 五种算法

记号：`E` = 用于定价的 EPS；`P25 / P50 / P75 / P90` = 本股 10 年 TTM PE 分位；`clamp(x, a, b)` = 把 x 限制在 [a, b]。

**稳定类**

- `E = 0.5 × eps_ttm + 0.5 × eps_ntm`（没有一致预期时 `E = eps_ttm`）。
- PE 法：悲观 = `E × 0.90 × P25`；中性 = `E × P50`；乐观 = `E × 1.05 × P75`。
- 自由现金流法：每股自由现金流 ÷ 要求收益率，悲观 6.0%、中性 4.5%、乐观 3.5%。
- 结果 = 0.7 × PE 法 + 0.3 × 自由现金流法（每档分别加权）。两种方法中性值相差超过 40% → 置信度降一档。

**成长类**

- `g` = min（一致预期次年 EPS 增速，3 年营收复合增速，40%）；没有一致预期时用 min（TTM EPS 增速，3 年营收复合增速，40%）。
- 中性：一年后的前瞻 EPS = `eps_ntm × (1 + g)`；一年后的前瞻 PE = `clamp(10 + 0.5 × g, 12, 35)`（g 用百分数，例如 30% 记 30）；且不超过本股 `P90`；价值 = 前瞻 EPS × 前瞻 PE ÷ 1.10（按 10% 折回今天）。
- 悲观：`g_bear = 0.5 × g`，PE = `clamp(10 + 0.5 × g_bear, 12, 30)`，同一公式。
- 乐观：`g_bull = min(1.25 × g, 50)`，PE = `clamp(10 + 0.5 × g_bull, 12, 40)`，同一公式。
- 附加展示"**当前价隐含的增速**"：令中性公式的价值等于当前价，反解 g。

**周期类**（归一化盈利，避免"景气高点 PE 最低"的陷阱）

- 常态净利率 `m*` = 近 10 个财年净利润率的中位数（至少 7 年；不足用板块参数，置信度降一档）。
- 常态营收 `R*` = 近 3 个财年营收均值；若 10 年营收复合增速 > 8%，再乘 `(1 + 复合增速)` 前移一年。
- 常态 EPS = `m* × R* / 稀释股本`。
- 悲观 = 常态 EPS × 0.85 × PE 低档；中性 = 常态 EPS × PE 中档；乐观 = 常态 EPS × 1.15 × PE 高档。

| 周期子行业 | PE 低 / 中 / 高 |
|---|---|
| 存储（HDD、NAND、DRAM） | 9 / 13 / 17 |
| 半导体设备 | 14 / 19 / 25 |
| 能源 | 9 / 12 / 15 |
| 机械 | 12 / 16 / 20 |

- 附加展示"**景气位置**"：TTM 净利率相对常态净利率的偏离，例如"当前利润率 20%，常态 12%，处于景气高位"。

**未盈利成长类**

- 未来 12 个月营收 = 一致预期；没有时用 `rev_ttm × (1 + min(rev_growth, 60%))`。
- EV / 营收倍数按增速分档，再按毛利率调整：倍数 × `clamp(毛利率 / 70%, 0.5, 1.2)`。

| 营收增速 | 悲观 / 中性 / 乐观 |
|---|---|
| ≥ 40% | 6 / 10 / 15 |
| 25%–40% | 4 / 7 / 10 |
| 15%–25% | 2.5 / 4 / 6 |

- 股权价值 = EV − 净负债；每股价值按稀释股本，悲观档股本 × 1.05。
- 现金跑道 = 现金 ÷ |TTM 自由现金流|；不足 1.5 年时悲观档 × 0.7，置信度为低。
- 这一类置信度最高为"中"。

**金融类**（银行）

- 合理市净率（有形）= `(ROTE − g) / (r − g)`，`g` = 4%；`r` 中性和乐观 10%、悲观 11%。
- ROTE 用近 5 年均值；悲观 −3 个百分点、乐观 +2 个百分点。
- 合理市净率限制在 [0.6, 3.0]；每股价值 = 每股有形净资产 × 合理市净率。

### 4.5 公共规则

- **顺序约束**：必须满足悲观 ≤ 中性 ≤ 乐观；不满足时按升序重排，并标记"方法异常"待复核。
- **位置 p** = `(价格 − 悲观) / (乐观 − 悲观)`。

| p | 显示 |
|---|---|
| < 0 | 低于悲观 |
| 0–0.35 | 偏低 |
| 0.35–0.65 | 中性 |
| 0.65–1.0 | 偏高 |
| > 1.0 | 高于乐观 |

- **估值不用当前价**：三档价值只由财报、一致预期、倍数历史决定；价格只用于计算 p。所以股价大涨大跌时区间不动、p 变化，这是"稳定估值"的含义。

### 4.6 更新触发与稳定性

| 触发 | 更新什么 |
|---|---|
| 每天收盘 | 只更新 p |
| 新 10-Q / 10-K 生效（按申报日） | 全部重算，包括类型判定 |
| 一致预期 `eps_ntm` 较上次使用值变化 > 3% | 重算 `E` 相关部分 |
| 每月第一个交易日 | 重算倍数历史分位 |
| 人工改类型 | 重算，留痕 |

**不触发**：新闻、价格异动、资金面变化、LLM 判断。

稳定性约束：

- 没有新财报时，单次重算中性值变化超过 25% → 新值标"待复核"，页面同时显示新旧两个值，复核通过后才替换。
- 每次变化都做**变化分解**：盈利变化、倍数变化、类型 / 方法变化、一致预期变化各贡献多少美元。
- 一致预期源失效时，自动退回 TTM 口径（稳定类 `E = eps_ttm`；成长类 `g` 用 TTM 口径），置信度降一档，页面标"一致预期缺失"。

**置信度**（高 / 中 / 低）从"高"开始，以下每条降一档：

- 倍数历史不足 5 年；
- 没有一致预期；
- 稳定类两种方法分歧超过 40%；
- 最近两期类型判定不一致；
- 外国申报人只有年度数据。

另外，未盈利成长类置信度最高为"中"。

### 4.7 示意算例（数字为示意，不是真实数据）

**WDC，周期类，存储子行业**

- 常态净利率 12%，常态营收 100 亿美元，稀释股本 3.5 亿股 → 常态 EPS = 3.43 美元。
- 悲观 = 3.43 × 0.85 × 9 = 26.2；中性 = 3.43 × 13 = 44.6；乐观 = 3.43 × 1.15 × 17 = 67.1。
- 当前价 70 → p = (70 − 26.2) / (67.1 − 26.2) = 1.07，显示"高于乐观"。
- 景气位置：TTM 净利率 20% vs 常态 12% → 景气高位。
- 东芝扩产后股价跌到 55：区间不动，p 降到 0.70，显示"偏高"；页面会写"价格回落，估值区间未变：东芝扩产尚未体现在财报或一致预期中"。

**NVDA，成长类**

- `eps_ntm` = 6.00；一致预期次年增速 35%，3 年营收复合增速 80% → g = min(35, 80, 40) = 35。
- 中性：6.00 × 1.35 × clamp(10 + 17.5, 12, 35) ÷ 1.10 = 6.00 × 1.35 × 27.5 ÷ 1.10 = 202.5。
- 悲观：g = 17.5 → PE = 18.75 → 6.00 × 1.175 × 18.75 ÷ 1.10 = 120.2。
- 乐观：g = 43.75 → PE = 31.9 → 6.00 × 1.4375 × 31.9 ÷ 1.10 = 250.1。
- 当前价 180 → p = (180 − 120.2) / (250.1 − 120.2) = 0.46，显示"中性"；当前价隐含增速约 30%。
