# v19 规则化方案：层级判定与跳空事件判定（2026-11-02）

> 用户 2026-11-02：层级、是否追高都不能靠人拍板，必须由规则判定；跳空高开要具体分析——基本面真变了（如 MSFT 财报后价值回归）可以跟，只是消息/情绪推动（如 MRVL 因一次演讲跳涨 20%）不能追。
> 本文取代 `v19-tiers-draft.md` 的人工初稿和 `chase_block`（5 日涨 8%）规则。参数为事先登记的初始值，只用回测检验，不按结果反复调。

## 一、层级判定规则

### 1. 只看慢变量，不看估值和短期价格

| 特质 | 指标（按财报申报日生效） |
|---|---|
| 成长 | 近四季营收同比增速（TTM）；近 8 季增速的稳定性 |
| 盈利质量 | 近四季自由现金流利润率；近 8 季自由现金流为正的季数；毛利率 |
| 风险 | 252 日年化波动率；252 日相对 SPY 的 beta；近一年最大回撤 |
| 财务韧性 | 现金 ÷ 近四季自由现金流缺口（亏损公司） |

估值不参与定层（切断“涨→估值分降→换层→门槛降→买入”）。

### 2. 判定（初始值）

- **进攻**：满足任一——营收 TTM 增速 ≥ 30%；或自由现金流为负 / 近 8 季为正少于 6 季；或 252 日波动 ≥ 45% 且营收增速 ≥ 15%。
- **防守**：同时满足——252 日波动 < 28%、beta < 0.9、近 8 季自由现金流全部为正、自由现金流利润率 ≥ 8%、营收增速 < 30%。
- **普通**：其余。

### 3. 稳定性

- 只在新财报申报后重评，不在日内或每日按价格变化重评。
- 换层要连续两个季度都满足新层条件；边界设缓冲（如波动率进入防守 < 28%，退出 > 33%）。
- 每次换层自动生成《换层记录》：哪几项指标、从多少变到多少。

### 4. 检验

- 2018 年至今逐季回放：每只股票每年换层次数（目标平均 < 0.5 次/年）、层级分布、各层的波动与回撤是否符合定位（防守层回撤应明显小于进攻层）。
- 不以“和人工初稿一致”为目标；与初稿不同的逐只列出原因，供参考。

## 二、跳空/急涨事件判定（取代“5 日涨 8% 不买”）

### 1. 触发

单日涨幅 ≥ 3 倍平时波动（与一期异动门槛一致），或 3 日累计涨幅 ≥ 4 倍平时波动。触发后进入判定，判定结果写入买入理由书。

### 2. 原因归类（用一期感知模块已有的数据）

| 类别 | 依据 |
|---|---|
| 财报 | 当天或前一交易日有 10-Q/10-K/8-K 2.02 申报、财报事件 |
| 实质事件 | 8-K 重大合同/并购/指引更新，且金额相对营收可量化 |
| 评级与预期 | 分析师上调、一致预期上修 |
| 叙事/情绪 | 只有新闻、讲话、社交媒体，没有申报或预期变化 |

### 3. 基本面是否被证实（打分）

- 财报：营收同比增速比上一季加速、毛利率/经营利润率扩张、（有数据时）营收和指引超一致预期。
- 后续确认：事件后 10 个交易日内一致预期上修（2026-10-17 起有数据）；价格守住跳空缺口（不回补）。
- 估值背景：事件前远期市盈率处于自身 3 年分位的位置；事件后的估值是否仍在合理区间（只作为“是否值得跟”的背景，不参与定层）。

### 4. 决策

| 判定 | 动作 |
|---|---|
| 基本面证实 + 事件前估值偏低（自身 3 年分位 ≤ 50） | 允许按信号买入（价值回归，如 MSFT） |
| 基本面证实 + 估值已高 | 不追，按回调买入区间等回踩 |
| 叙事/情绪，无申报和预期变化 | 不买，进观察名单；等下一份财报证实后再评估（如 MRVL） |
| 证据不足 | 按回调买入区间处理 |

### 5. 历史可回测的范围

- 2018 年以来可用：申报日期与财报数据（SEC）、行情、异动判定 → 可区分“财报/申报驱动”与“无申报驱动”，可算营收加速与利润率变化、缺口是否回补、估值分位。
- 一致预期、新闻原因分类只有 2026-10 起的数据 → 这部分只能前向影子评估。
- MSFT、MRVL 只是用户事后举的例子，**不作为评价标准**（用户 2026-11-02）。规则以数据独立判断，回测中只列出这两例的判定结果供参考。

## 三、回测安排

1. 规则层级 vs 规则 A 自动层级 vs 人工初稿，三者对比（层级稳定性 + 收益/回撤）。
2. 跳空判定规则 vs 不拦截 vs 旧 8% 拦截。
3. v19 组合 = 规则层级 + 回调买入区间 + 冷却收复 + 跳空判定。
4. 稳健性：去掉贡献最大的标的、不同起点（沿用 2026-11 稳健性检验的做法）。
