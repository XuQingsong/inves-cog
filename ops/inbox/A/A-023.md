## 接口（B-063 按此读取，不得改名）

1. **VIX 备用源**：`ingest.macro_observations` 新增 series_id `VIX_YAHOO`、`VIX3M_YAHOO`（Yahoo chart `^VIX`、`^VIX3M` 日收盘），与 `VIX_CBOE` 同结构。每天两源都采（CBOE 失败不阻塞 Yahoo）。补采 2026-10-01 起缺失日，10-23 应为 19.45。
   - 交易读取端（`trading/execution/repository.py`）优先级改为 `VIX_CBOE → VIX_YAHOO → VIXCLS`；v18 回放必须不变（回放区间 CBOE 齐全，测试证明）。
2. **财报日历**：新表 `ingest.earnings_calendar`
   `(ticker text, report_date date, time text CHECK (time IN ('pre','post','unknown')), eps_forecast numeric NULL, n_estimates int NULL, market_cap numeric NULL, company text, source text, fetched_at timestamptz, PRIMARY KEY (ticker, report_date, source))`
   每天 ET 06:00 采 Nasdaq 未来 10 个交易日；Nasdaq 失败时对持仓+标的池用 Alpha Vantage `EARNINGS_CALENDAR` 补（注意 25 次/天）。
3. **宏观日历**：新表 `ingest.econ_calendar`
   `(event_date date, event_time_et text NULL, country text, name text, actual text NULL, consensus text NULL, previous text NULL, source text, fetched_at timestamptz, PRIMARY KEY (event_date, country, name, source))`
   Nasdaq economic events，采当周与下周，只存 country='United States'。重要事件筛选由页面层做，采集层全存。
4. **source_health**：上述每个源（CBOE、Yahoo VIX、Nasdaq 财报、Nasdaq 宏观、Alpha Vantage、Alpaca 新闻）每次采集写现有 `ingest.source_health`（成功/失败、条数、最新数据时间、错误摘要）。

## 其余工作

5. **新闻断档**：查明 10-16～10-24 无新新闻入库的原因（怀疑与费用暂停/看门程序有关），写进答复；加监控：交易日 ET 10:00 后连续 2 小时 Alpaca 新闻 0 条入库，source_health 记失败。
6. **停止逐条新闻大模型**：粗筛与完整提取默认关闭（配置开关，代码保留）；新闻照常入库，不再因预算 pending。现有 pending 不再处理，标 `rules_only`。保留调用路径给 B-064 的大事归因。
