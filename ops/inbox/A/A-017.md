## 要求

1. **只读运行**：页面服务用 `INVES_COG_WEB_DATABASE_URL`，登录账号只继承现有 `role_web`（开启 LOGIN、随机密码只存服务器私有 env；与 M9 两个角色的 LOGIN 一并等用户在 A 对话直接答复，不得借用其他账号或管理员账号）。
2. **进程**：新增 supervisor program 运行 uvicorn 承载 `inves_cog.web.api`，监听 `0.0.0.0:8080`，单 worker；以 claudeuser 运行；只重载这一个新进程。
3. **最小防护**（不改变“无密码”决定）：只暴露 `GET /api/pages/*` 与页面渲染所需路径，其他方法返回 405；关闭 FastAPI 自动文档页（`/docs`、`/openapi.json`）；每 IP 简单限流（如 60 次/分钟）；错误响应不回显异常堆栈与连接串。
4. **端口开放**：服务器防火墙/云安全组放行 8080 需 root 或云控制台，由用户执行；A 在 status 写明需要放行的端口和协议，不自行改防火墙。
5. 部署后回报：外部访问 `http://<公网IP>:8080/api/pages/?date=…` 的状态码、首页 JSON 是否含当日计数、进程 RSS。
