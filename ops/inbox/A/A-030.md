# A-030 隐含天花板上线（展示与风险提示）+ V 利润数据修复

> 依据：`docs/phase2/valuation-system.md`（估值体系 v1）、A-029 验收结论（`ops/answers/A-029.md` 末尾）。
> 背景：历史标普 500（含被剔除公司）检验显示，隐含天花板最透支的五分之一持有 1.5–3 年明显跑输；“便宜就涨”不成立；1 年内无信号。A-029 证明它不宜用作短线买卖规则。因此本单只做**展示与长期风险提示**，不改规则 A 的任何交易行为。
> 授权（B 线不在线，用户 2026-11-05 指定由 A 开发）：`src/inves_cog/valuation/`、`src/inves_cog/valuation_v1/`、`src/inves_cog/trading/`（仅计划理由文字）、`src/inves_cog/web/`（页面展示）、`src/inves_cog/ingest/fundamentals/`（仅第 4 项 EPS 修复）、`migrations/`（valuation_v1 新表）、`scripts/`、测试与本单文档。

## 2. 每日计算隐含天花板（valuation_v1）

- 新表 `valuation_v1.ceiling_daily`（主键 ticker + trade_date），由现有 `valuation_v1` 服务在其每日运行中写入，覆盖监控池全部标的。字段至少：
  - `method`：`growth`（常规，书中表 1-3）/ `loss`（利润 ≤ 0 或 m > 40，用表 1-8 的隐含终局利润）/ `cyclical`（不给档位）/ `financial`（银行保险，不给档位）；
  - `r`（防守 7%、普通 8%、进攻层/亏损/强周期 10%，取当日规则 A 层级；缺层级用 8% 并在 missing 中注明）、`m`、`m_r_minus_1`、`m_r_plus_1`；
  - `fcf_m`（FCF/净利润 < 0.5 时另算的现金口径 m）、`quality`（高/低）；
  - `band`（可信 / 偏高 / 严重透支 / 不适用）、`band_rule`（所用阈值版本）、`evidence`（JSON：一致预期 FY2 覆盖度、营收增速与加速度、毛利率趋势、ROIC、FCF/净利润——仅展示，本单不参与定档）、`missing`（缺失项列表）、`asof`。
- 输入沿用 `src/inves_cog/valuation/ceiling.py`（已复现书中表格）与估值体系 §1：EV = 市值 + 净负债，稀释后股数，正常化税后经营利润。只用决策日已公开的数据（PIT）。
- **定档规则（不靠人工判断）**：用 Mac 本地 `~/inves-cog-bt/valuation/panel_sp500.csv`（历史标普 500，r=8%）计算最近 52 周每周 m 的 60 与 80 分位，取 52 周中位数作阈值：m ≥ 80 分位阈值 → 严重透支；60–80 → 偏高；其余 → 可信。阈值写入版本化配置 `config/valuation_ceiling_bands.yaml`（含校准日期、数据来源、样本数），并提供 `scripts/calibrate_ceiling_bands.py` 供每季度重算。生产不读取 Mac 文件。
- 周期股与金融股的识别：先查 `valuation_v1` 现有的周期/金融分类并复用；若没有现成分类，按 §5.1 一次性提问，默认值为“现有行业/板块字段中的存储、半导体设备、能源、原材料为周期；银行、保险为金融”。

## 3. 展示与风险提示（不改交易）

- 个股页：在现有估值区展示 m、档位、r、r±1% 敏感性、现金口径 m（如有）、证据项和缺失项。文案示例：“现价隐含利润约涨到现在的 3.2 倍（折现率 8%），处于偏高档”。档位不适用时写明原因（周期股/金融股/亏损）。
- 持仓与计划页：持仓若处于“严重透支”，加提示“长期回报大概率偏低（隐含天花板处于严重透支档）”；这是提示，不是卖出信号，不进入风险计数。
- 纸面计划买入理由：追加一句隐含 m 与档位。规则 A 的买卖决策、数量、价格完全不变。
- 页面不再出现“市盈率历史分位”“PE ÷ 增速”作为估值合理性的说法（如现有页面有，替换为隐含天花板或删除）；`valuation_v1.ranges` 的现有区间展示保留。
- 遵守页面禁用规则：无目标价/合理价、无下单按钮、无“实时”、无内部编号或 `None`；缺数据必须明示。
