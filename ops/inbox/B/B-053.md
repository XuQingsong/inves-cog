## 计算口径（允许的派生值，集中在 `brief.py`，公式写在页面脚注与测试里）

M10“页面不重算”放宽为：页面可做**简单派生**（平均、比值、按参数表计算的价位），但只能在 `brief.py` 一处实现，每个派生值有测试按公式逐值核对；不得重算分数、状态、估值。
- 主题平均涨跌 = 该主题成员当日收益算术平均；成交量倍数 = 当日成交量 / 前 20 日均量（`ingest.bars_daily`）。
- 止盈线 = `avg_cost × m4.sell.double_price`；灾难止损线 = `max(peak_price, 现价) × m4.sell.disaster_peak_fraction`；200 日线 = `price / (1 + price_vs_ma200/100)`；破位天数取 `m4.sell.below_days[tier]`；参数从 `config/params/<版本>/m4.yaml` 读取，不写死。
- 50 日线 = `price / (1 + dev50/100)`；一年高点 = `price / (1 + drawdown252/100)`。
- 一句话结论用规则模板（不调模型）：领跌/领涨主题与幅度 + 判断：`IWM−QQQ > 2 个百分点且上涨家数 > 下跌家数` → “板块轮动而非全面恐慌”；`SPY ≤ −2% 且上涨家数/下跌家数 < 0.5` → “普跌”；其他 → “分化”。阈值写成常量并在测试中覆盖三种情形。
