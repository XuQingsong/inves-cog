# B-036 · 持久化 M8 PIT 输入快照，让 M9 能使用真实事件字段

> 发给：B 线（Cursor）。前置：B-035/PR #46 已验收并合并（merge `0cd0ee5`），但它只能安全识别 M8 job 和字段缺口；事件字段没有 PIT 版本时仍 incomplete。
> **用户决策 UD-COORD-26：** 用户说 M8 PIT provider 是必须项并要求直接开始。授权本单范围内新增最小 append-only `perception` 快照 schema 和既有角色最小权限。不是一般性放开 schema/权限：只限本任务的 M8→M9 PIT snapshot。

## 目标

M8 的当前表会更新事件状态，缺少机制保存“这个交易日 M8 完成时，M9 实际可见的事件/标签字段”。需要由 M8 在完成当日必需阶段后保存不可变快照；M9 按页面/运行 cutoff 读取当时已存在的快照。这样不能用后来更新的 lifecycle、exposure 或报告冒充先前可见。

## 数据结构和权限（一次性授权）

新增 `perception.m9_input_snapshots`（名称可在开工说明中微调，语义不变），只追加，不 UPDATE/DELETE。至少保存：

- `trade_date`、真实 `snapshot_generated_at`、M8 输入 `source_asof`、完整/降级状态；
- 完成该快照的实际 M8 job IDs、job statuses、结束时间；
- 每个 event 的 `event_id`、`anomaly_id`、生命周期及当时可见版本、affected ticker/exposure、mechanism、direction、divergence/systemic tags、dimensions、next filing 等 M9 所需字段；
- source IDs、原始 published/observed/captured times，以及字段级 `missing_reason`。

权限只限现有角色：`role_perception` 对该表 INSERT/自身必要只读；`role_shadow` 仅 SELECT。迁移按最小权限 GRANT；不创建新角色，不扩大到其他 perception/M8 表，不借管理员运行日常 job。

## 写入和 PIT 规则

1. 仅在 `attribution_candidates`、`attribution_tracks`、`attribution_labels` 的当日 job 均在 cutoff 前成功结束后，M8 写一份该 trade date 的快照；空事件列表只有在各阶段确认运行成功时才表示“已查过且无事件”。
2. `snapshot_generated_at` 用注入 Clock 的实际时间；`source_asof` 取真实输入可见时间/完成标记，不用 trade date 或人为回填时间。
3. cutoff 之后产生/修改的源信息不进入该快照。每个字段带真实来源时间；缺少可信时间时写 NULL 和原因，不用当前值追认历史。
4. M9 只读 `snapshot_generated_at <= M9 cutoff` 的最近完整快照；不存在完整快照就返回 incomplete/degraded，由 M4 原有缺失行为处理，不生成“完整”空覆盖层。
5. 历史数据：检查已有 source history；只有原始 source IDs 与发布时间/采集时间可证明 PIT 时才允许做 `historical_backfill` 快照，记录实际生成时间并明确标为 backfill，绝不让它出现在更早页面/计划。无法证明的历史维度维持 unknown，不伪造。

## 开发与验收

- 只改 M8 `perception` 快照迁移、M8 完成后写入和 provider 读取接口，以及相关 Harness 测试；不改 M9 `overlay/shadow`、M4 调度、规则 A、阈值、外部数据源或模型。
- 先写失败测试，覆盖：所有阶段成功且无事件、事件字段完整、部分字段无 PIT 时间、缺 job/失败 job、cutoff 后 job/事件、同事件多版历史、实际 injected clock、只追加不可覆盖、角色权限边界、M9 读不到未来快照。
- 无生产迁移、无历史生产回填、无部署。`make phase1-test`、相关 cases 与准确 head CI 通过后开 PR；由需求方验收合并。PR 合并后 A 在其 M9 分支接入 provider。
- 如果现有 M8 输入无法给出原始来源时间，按字段列出真实缺口并停在数据/契约边界；不要因表结构存在就标 complete。若需新增外部来源/密钥/角色，停下请求授权。
