## 为什么有这张单

用户 2026-10-19 读了每天那一页的说法后说：不要出现「库里」「数据库」这类话，界面是给用户看的，不是给开发和程序员看的。

现在的页面上有新闻的内部编号（`news:benzinga:62355815`）、「入库新闻里没有对得上的」「新闻卡标了高」「篮子」「没有持仓快照」、英文字段名、`None`、「跌 -5.7%」、十几位小数。两次波动的解释和归类分开堆在两处，分不清哪句属于哪次。59 只估值全部列出，没有现价。

「提前看到」的规则也要改。原来只要波动前有相关新闻就写「提前看到」，不管解释有没有用上。所以 10 月 14 日、15 日同一页出现「提前看到」和「没有对得上的」。这是需求方写的规则不对。B-015 到 B-026 按单做完，不打回。

需求写在 `docs/phase1/news-and-moves-phase1.md` 第 11 节，那里有整页样子。

## 什么时候发生，什么时候不发生

发生：北京时间 09:15 的 `run_scheduled` 写每天那一页时。

1. **开头**一行：「YYYY-MM-DD 收盘后」。
2. **一、昨天不寻常的波动。** 每次波动一组，组内依次写：
   - 第一行：一只写「代码 跌 5.7%」；多只写「N 只一起跌，平均跌 7.4%：」接代码，用顿号。百分号前不带负号，涨跌写在字上。
   - 「可能的原因：」后接解释，每条一句话加强中弱，再接来源和北京时间（例如「Benzinga 10月14日 21:05」）。来源从新闻编号的第二段取（`news:benzinga:…` 写 Benzinga，`sec_8k:…` 写 SEC 8-K）。没有解释，写「可能的原因：没找到能解释这次波动的新闻」。
   - 「我们当时看到了吗：」后接下面六句之一。
   - 事后找到的新闻，写「事后找到、当时还没收到的：」，最多 3 条，每条一句话加来源和北京时间；发布晚于波动开始的，末尾写「（波动开始后才发布）」；多于 3 条写「另有 N 条」。
   - 没有波动：「昨天没有不寻常的波动」。
3. **二、影响大盘和多个行业的新闻（最多 5 条）。** 选法和排序不改。每条一句话，后接「影响 N 家」；含持仓时再接「，含你的持仓 代码」。原来折叠成「标了名单里的一大片」的，写成「影响 N 家」。这一档没有时，写「今天没有」。
4. **三、你的持仓。** 选法不改。每只一行「代码：一句话 利好/利空/不确定」；同一只还有更多时接「。另有 N 条」。碰上当天波动的，末尾写「（今天也有不寻常波动）」。没有重要新闻的持仓写「今天没有重要新闻：」接代码。拿不到持仓时写「今天没有拿到持仓」。其余没展开的写「另有 N 条较重要的新闻没有列出」。
5. **四、值多少（美元）。** 只写持仓、当天波动里的、当天计划单里的股票，去重，按代码排序。
   - 能估：「代码 现价 X｜偏低 X｜中间 X｜偏高 X」，两位小数。
   - 现价从这一行的 `price` 或 `payload.price` 读。拿不到现价，或者中间那档低于现价三分之一、高于现价 3 倍：「代码 现价 X｜估值待复核」（拿不到现价时不写现价）。
   - 不估：原因里有「金融」写「暂不估值：金融类公司，缺所需财务数据」；有「亏损」写「暂不估值：亏损且没有增长，按规则不估」；其余写「暂不估值：所需财务数据不全」。
   - 末尾写「其余 N 只不在这一页」，N 是当天有估值行、但没列出的只数。
   - 拿不到估值：「今天没有拿到估值」。
6. **五、今天的纸面计划（规则 A，不是真实交易）。** 每单一行「代码 动作 约 22,869.85 美元」，金额千分位、两位小数；有股数时接「，N 股」。没有单：「今天没有计划单」。拿不到计划：「今天没有拿到计划」。
7. 最后一行：「新闻和波动的解释，不会改变估值和计划。」

**「我们当时看到了吗」六句：**

| 说法 | 什么时候 |
|---|---|
| 波动前已经看到这条新闻 | 解释里至少一条「当时已经知道」为真 |
| 有相关新闻，但没认出是原因 | 原来算成「提前看到」，但解释里没有一条「当时已经知道」为真 |
| 收到了新闻，但没认出和这只股票有关 | 原来的「入库了但没标到」 |
| 当时没收到这条新闻，事后才找到 | 原来的「没采到」 |
| 没找到相关新闻 | 原来的「查过没有消息」 |
| 新闻和波动是同一天，分不清先后 | 原来的「同一天，发布钟点不清楚」 |

不发生：不改新闻卡和波动卡的问法，不调模型，不改一档最多 5 条、持仓逐只列的选法，不改再查一次，不改估值和计划的计算，不从计划单反推持仓。

## 先红后绿

例子都从 `run_scheduled` 跑。交易日 2026-10-14，调用时间 2026-10-15 09:15（北京）。

1. **两次波动各自一组。** 一次 JNJ 跌，解释一条，`当时已经知道` 为真；一次 AMD、NVDA 一起跌，没有解释，原来算成「提前看到」。页上 JNJ 那组有「可能的原因：」和「波动前已经看到这条新闻」；AMD 那组有「2 只一起跌」「没找到能解释这次波动的新闻」「有相关新闻，但没认出是原因」。全页没有「提前看到」。
2. **事后找到的新闻。** 一次波动，补查到 4 条，其中 1 条发布晚于波动开始。页上有「事后找到、当时还没收到的：」、3 条、「另有 1 条」，晚发布的那条若在前 3 条内带「（波动开始后才发布）」。
3. **其余四种说法。** 原来的「入库了但没标到」「没采到」「查过没有消息」「同一天，发布钟点不清楚」各一例，页上分别是表里的新说法。
4. **估值只印该印的，离谱的不印数字。** 持仓 NVDA、UNH；波动里 JNJ；计划单 MU；另有 AAPL 一行估值。NVDA 现价 217.23、中间 969.66；JNJ 现价 253.28、中间 235.49；MU 没有现价；UNH 不估、原因含「金融」。页上有「NVDA 现价 217.23｜估值待复核」「JNJ 现价 253.28｜偏低」「MU 估值待复核」「UNH 暂不估值：金融类公司，缺所需财务数据」「其余 1 只不在这一页」。没有 AAPL。
5. **计划金额。** 一单 MU 确认加仓，金额 22869.85093940002，没有股数。页上是「MU 确认加仓 约 22,869.85 美元」。
6. **全页不出现内部用语。** 用上面每个例子的页面，逐字检查不出现：库、入库、数据库、新闻卡、波动卡、标了高、名单内、名单外、篮子、快照、编号、归类、`news:`、`sec_`、`None`、「-」紧挨数字后接「%」、超过两位的小数，以及任何连续英文小写加下划线的字段名。

B-018 到 B-026 例子里断言旧说法的地方，按本张改成新说法。这是本张要改的行为，不是之前的单没做对。
