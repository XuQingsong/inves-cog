# B-012 点名规则进入门禁

> 发给：B 线（Cursor）。日期：2026-10-18。类型：修复（不经过 G1）。需求方：Cursor 云端协调方。不发起模型调用，不连数据库。

## 为什么是这一条

M8 这批 19 次调用已经完成。过不了不是接口或模型故障。已经定过的规则是：假说可以新开一条链路，但不能把材料没点到的股票写进名单；每只股票要有自己的为什么和证伪。现行门禁只检查链路终点的字符串是不是股票代码，不检查原句里有没有这家公司。

因此原句没有 Meta，META 三次都被留下；原句写了 CoreWeave，三次都被删掉；戴尔三次里只有一次能留下。这就是要修的行为。不改提示词，不再调用模型，不改评分。

## 基线

继续在 PR #21 的分支 `cursor/m8-b009-links-e013` 上提交，基线不早于 `820e5e9`。不新开 PR。不改 PR #17、#18、#19、#22、#23。

## 修复项

只改候选进入「预期影响范围」的规则。市场层和经营层仍只由规则填写，模型写的同名字段继续剔除。评分公式、权重、阈值不动。

对模型放进 `affected` 的每只股票，只按下面两条决定留不留。不在 `affected` 里的股票，不得因为标题里出现了公司名就新加进去。

1. **材料点名。** 至少一条合法引文（必须是材料原文里的连续片段）以整词出现这只股票的代码，或出现下面的公司名。链路终点写成短语还是代码都一样，这种留下不要求证伪预测。终点字符串里出现代码不算点名，只有引文算。

   | 代码 | 引文中的公司名 |
   |---|---|
   | CRWV | CoreWeave |
   | DELL | Dell |
   | NTAP | NetApp |
   | STX | Seagate |
   | WDC | Western Digital |
   | META | Meta |
   | NVDA | Nvidia |
   | AMD | AMD |
   | AVGO | Broadcom |
   | MSFT | Microsoft |
   | ORCL | Oracle |
   | SMCI | Super Micro |
   | MRVL | Marvell |
   | VRT | Vertiv |
   | ETN | Eaton |
   | TSM | TSMC |
   | ANET | Arista |
   | GEV | GE Vernova |

   匹配不区分大小写。短名字按整词，避免把别的单词里的字母当成代码。上表没有的代码，只认代码本身的整词。

2. **声明的假设。** 原句可以没有这家公司。留下必须同时满足：一条合格的「声明的假设」终点就是这只代码，这只代码有自己的一条证伪预测，而且没有和另一只股票共用同一段假设文本加同一条证伪。共用的那些全部不留。标成「来源陈述」但引文没有这家公司的，不能靠这条留下。

## 必须先红后绿的例子

1. 引文含 `CoreWeave Bond Yield Hits 15%`，终点是板块短语，`affected` 为 CRWV、NVDA。只留 CRWV。NVDA 进入缺口。
2. 引文是 `Muse is the No. 1 free iPhone app in America`，来源陈述终点为 META。META 不留。
3. 引文含 `Toshiba to double hard disk drive supply`。来源陈述终点为 STX；声明的假设终点为 WDC，且 WDC 有合格证伪预测。只留 WDC。STX 不留。
4. 引文含 `Barclays Downgrades Dell Technologies`，终点是短语，`affected` 为 DELL、SMCI。只留 DELL。
5. 引文是 `DeepSeek R1 was released`，终点是短语，`affected` 为 NVDA、AMD。一只不留。
6. 材料标题里有 NetApp，但 `affected` 没有 NTAP。不新增 NTAP。
7. 同一段假设文本、同一条证伪，两只股票都把终点写成自己的代码。两只都不留。
