## 工作包一：逐环依据与显式假设（核心）

1. 候选输出新增逐环结构 `links`：传导链上每一步（起点实体 → 终点实体或标的）必须恰好属于一类：
   - `来源陈述`：至少一个原文锚点（沿用现有 info_id + 字段/段落 + 逐字引文的锚点机制）。允许多个锚点合成一步，此时标记 `组合`，并写明各锚点分别提供什么；
   - `已有关系`：引用 `as_of` 时可见、状态不低于"观察到"的图谱关系 id（沿用 `graph_context`），不能用当前图谱倒推当时已知；
   - `声明的假设`：写明假设内容、类型（产业结构 / 需求弹性 / 暴露关系 / 其他）和证伪条件（可观测指标、方向、观察窗口）。
2. 候选级新增：`竞争解释`（列表，可以为空，但必须显式给出）、`反证条件`。
3. 预期影响范围里的每个标的必须有一条到达它的 `links` 路径。路径上有 `声明的假设` 时，该标的必须有**只针对它**的证伪预测（相对哪个对照篮子、什么方向、什么窗口）。
4. 只做确定性检查：结构；锚点逐字匹配（现有）；关系 id 存在且当时可见；假设是否带证伪条件。多个标的共用同一假设和同一预测时，标记 `共用假设`，在宽度和计数里按一项计。没有路径的标的移入研究缺口并写明原因，不静默丢弃，也不进入预期范围。
5. 保留现有 `affected` 字段，其内容等于预期影响范围，避免破坏已有读取方。机制集合、最多 5 个候选、`forbidden` 字段都不变。
6. 提示词版本升为 `evidence-bridge-v3-links`。payload 哈希随之改变；旧录音不得重新标成 v3。
7. 报告分开显示：来源陈述、已有关系、声明的假设、缺证项、三层范围。报告固定写明"引文匹配只证明出处，不证明支持推断"。

## 工作包三：诊断实验工具（离线，只生成，不执行调用）

一个命令行入口，输入冻结的对象材料，输出以下内容。所有输出都带哈希和生成顺序记录：

1. **四格 payload**：原始材料 / 补齐材料 × 模型抽取 / 人工参考抽取。
   - 补齐材料必须在该对象的 `as_of` 之前已公开，并且要在参考答案文件生成**之前**登记到一个预登记清单里（工具检查哈希和时间先后，违反就拒绝生成）；
   - 每一格只能使用该格允许的材料；
   - 参考答案是一组可接受假说，分三档：可接受 / 不可接受 / 集合外待盲审。不是唯一的"真实原因"。
2. **删除变体**：删除目标信息时，同时删除它的摘要、抽取说法和同源转述（沿用现有来源根或叙事去重逻辑）。输出要记录删除了哪些条目。
3. **安慰剂对象**（无异常的交易日和篮子）与**方向反转对象**（新闻不变，异常方向取反）。
4. **盲审表**：打乱顺序、隐藏组别，组别映射单独存放。
5. **调用计划（只读）**：每格调用次数、payload 哈希、合计上限。本工具不含实际调用路径；执行由需求方在用户授权后另做。
6. **离线诱饵评分**：输入人工写的正确候选和诱饵候选（时机好、共现多、但没有桥接），直接调用现有评分函数，输出排序表。附一个合成夹具和测试。
7. **复评工具**：给定本机已有的候选响应和人工复核结论（路径由调用方传入，不进仓库），输出每个候选各评分分项的来源条目和工作包二的标记。仓库里只放代码和合成测试。
