# B-073 页面改版：突出重点、颜色分级、代码可点击与搜索、个股详情页

> 来源：用户 2026-10-31 反馈——内容多但没有重点；颜色单一，看不出哪些要关注；信息不联动，例如 INTC 只知道跌了 −28.58%，不知道跌到多少、近期走势如何。
> 执行：SWE-2（开发、预览、部署）。授权：`src/inves_cog/web/`（含 js/css 与路由）、测试。web 只读、只格式化，不重算交易规则，不新增数据库写入；不引入外部 CDN 或前端框架（内联 SVG + 现有 `investor.js`）。
> 流程：先部署到预览 8091，需求方和用户看过截图后再合并、上生产。

## 1. 统一视觉规则（所有页面）
- 颜色变量集中定义：`--up`、`--down`（沿用现有页面的涨跌配色，不改约定）、`--alert`（重大，深红底白字徽章）、`--watch`（关注，琥珀色）、`--info`（蓝）、`--muted`（灰）。
- 重要程度徽章三级：**重大**（|z| ≥ 5、核心公司财报不及/超预期 ≥ 20%、持仓触发卖出规则）、**关注**（其余活跃异常、核心公司 3 天内财报、持仓相关强事件）、**一般**。徽章只由已有数据推导，规则写在一个函数里并有测试。
- 每个模块有统一的卡片样式：标题左侧色条按模块类别区分（异常、财报、新闻、市场、持仓），标题右侧写数据时间。
- 事件类型 chip 分色（财报/指引、资本支出、并购、供应、监管、评级/其他）。
- 数字：涨跌一律带颜色和正负号；价格与涨跌同时给出（“$75.00 −28.6%”）。

## 2. 首页：先重点，后明细
自上而下：
1. **今日要点**（新，最多 5 张卡）：按“重大 > 关注”和 |z| 排序，从活跃的市场/板块/个股异常、持仓卖出规则触发、今明两天的核心财报中选取。每张卡一句话：对象（可点击）+ 现价与涨跌 + 起因一句（事件结论 chip）+ 徽章。没有可选内容时写“今天没有需要重点关注的异常”。
2. **实时异常**：改成紧凑表格——层级、对象、现价、涨跌、倍数、首次出现（北京/美东）、起因（单行、超长截断、悬停看全文）、状态。板块成员默认折叠（`<details>`）。
3. **财报**：即将发布用小表（日期、北京时间、代码、盘前/盘后、期权预期、一致预期 EPS）；已发布每张卡默认折叠，摘要行为“代码 · 次日投票 −28.6% · 结论 chip · 同环节跟随 2/0 · 期权参照”，展开看事件和反应。
4. 持仓与标的异动、热门主题新闻保持展开；滚动新闻、财报日历、涨跌排行等次要模块默认折叠。
5. 去掉现在“实时异常”“财报”模块中的长段纯文本堆叠。

## 3. 代码可点击、可搜索
- 新增唯一的代码渲染函数，所有出现股票代码的位置都用它输出 `<a href="/s/CODE">`：异常对象与板块成员、财报卡与同环节公司、新闻 chips、财报日历、涨跌排行、热门主题、持仓、纸面账户页、个股页的同行。写一个测试扫描首页与个股页 HTML：页面中出现的已知代码文本都包在 `/s/` 链接里。
- 顶部导航加搜索框（所有页面）：输入代码或公司名，回车跳转；下拉候选来自标的池、核心公司、持仓（代码 + 中文/英文名）。新增 `/search?q=`：精确代码命中则跳转；名称唯一命中则跳转；多条候选列表；没有则提示。
- 不在标的池的代码：只要 `ingest.bars_daily` 有数据，也能打开个股页（只显示价格和走势，其他模块写“不在监控范围”）；没有数据时显示“没有这只股票的数据”和搜索框。

## 4. 个股详情页 `/s/CODE` 重排
1. **顶部行情条**：代码、名称、所属环节与标签（持仓/标的池/核心公司）；**现价大字** + 涨跌额 + 涨跌幅 + 时段与时间（盘前/盘中/盘后/收盘，取最新快照，否则收盘价，标明来源）；今日高低、52 周高低与当前位置、成交量与量比、下次财报日期。
2. **走势图**（加大，占满宽度）：日线收盘折线，区间切换 1 月 / 3 月 / 6 月 / 1 年（页面内嵌数据，JS 切换，不再请求）；叠加 50/200 日均线；标记财报日、异常日（收盘批处理异常与实时异常）；悬停显示日期、收盘价、当日涨跌。规则 A 的线只画适用的（沿用现有规则）。有当日分钟快照时，图右侧附当日走势小图。
3. **今天发生了什么**：该股及所在板块的实时异常、起因事件和结论、财报卡（沿用 B-072 卡片，改为新样式）。
4. **同环节与同篮子**：同行表格（代码可点、现价、今日涨跌、5 日涨跌），一眼看出谁跟着动。
5. 之后依次为：新闻与事件、位置与情绪、四项评分与原因、基本面与估值、数据时间。

## 5. 验收
- 预览 8091 截图：首页（1440 宽，首屏和全页）、`/s/INTC`、`/s/AMD`、一个不在标的池但有日线的代码、一个不存在的代码、`/search?q=intel`。
- 测试：徽章分级函数；代码链接覆盖扫描；搜索跳转三种情况；个股页现价与涨跌取数（快照优先、收盘回退、来源标注）；走势图数据区间与标记点。
- 页面禁用词照旧；定向测试 + 准确 head 的 `phase1-blocking` 通过。
