> 发给：B 线（Cursor）。B-050 合并后开始，基于当时 main 新开 PR。B 只做工程实现。授权：`src/inves_cog/web/`（含 `public.py` 的路径白名单，仅新增本单的 GET 页面路径）与 `tests/m10/`。不新增依赖（不用 Jinja 等模板库，用标准库 `html.escape` 生成 HTML），不改上游、迁移、合同，不部署。
> **目标**：用户用浏览器打开 `http://<IP>:8080/` 即可阅读每日页面。交付后直接验收合并。提交前逐项完成 `ops/answers/B-051.md` 的 H1–H7。

## 要求

1. **路径**：`/`（系统日志首页）、`/market`、`/linkage/{id}`、`/stock/{symbol}`、`/graph`、`/settings/data`、`/paper/plan`、`/paper/portfolio`、`/paper/universe`、`/paper/stock/{symbol}`、`/paper/health`、`/paper/ledger`、`/review`，均支持 `?date=`，默认最近一个已到截点的美股交易日。
2. **只渲染 JSON**：每个 HTML 页面在服务端调用同名 `/api/pages/<name>` 的同一构造函数取得 JSON 后渲染；页面不查数据库、不计算任何数字（FR-M10-01、I36）。
3. **可读性**：中文界面、顶部导航与日期切换；首页先显示一句话摘要、计数、未处置清单（标红项醒目）；处置卡显示 ①–⑤ 的中文含义；“未接通”“数据暂缺”“今日未更新（原因）”“输入完整性未报告”原样显示；`/paper/*` 顶部固定标注“纸面跟踪，非投资建议”，估值区域标“估值参考 v1，不参与仓位”。纯服务端 HTML + 少量内联 CSS，不加载外部脚本/字体/CDN；手机宽度可读。
4. **分区**：市场与研究页面的 HTML 同样不出现订单、仓位、估值区间（按 B-048 的字段清单检查渲染结果文本与 JSON 来源）。
5. **安全**：所有动态文本 `html.escape`；只读；沿用 A-017 的方法限制、限流、错误脱敏；新增路径只允许 GET。
