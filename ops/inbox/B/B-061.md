## 背景（需求方读 `src/inves_cog/trading/execution/sells.py` 后确认，是需求方 B-053 规格缺陷）

B-053 给所有持仓统一画了“止盈线（2×成本）/200 日线/灾难止损线”，与规则 A 实际执行不符。`sell_signal` 的真实顺序与适用范围：

| 规则 | 适用 | 触发条件（参数来自 `m4.yaml`） | 动作 |
|---|---|---|---|
| M-50 基本面清仓 | 所有 | 质量分 < `death_quality[tier]` 或成长分 < `death_growth[tier]`，或红线（现金流为负且营收下滑/营收与EPS同时明显下滑），或 `fund_bad`；进攻层另加营收增速 < 0 或 runway 不足 | 全部卖出 |
| M-51 灾难止损 | **仅进攻层** | 现价 ≤ `disaster_peak_fraction` × 持有期最高价 **且** 低于 200 日线 | 全部卖出 |
| M-52 观察波段仓 | **仅 swing_only** | 止盈：dev50 ≥ clamp(vol20, `swing.take_profit`)；止损：现价 ≤ `swing.stop_fraction` × 成本 | 止盈卖波段/止损全卖；**其余规则对观察波段仓不适用** |
| M-53 波段部分止盈 | 核心仓且 swing_shares>0 | dev50 ≥ clamp(vol20, 进攻层 `attack_take_profit` / 其他 `take_profit`) | 卖波段部分 |
| M-54 翻倍分批止盈 | **仅进攻层** | 现价 ≥ `double_price` × 成本 且（dev50 < `double_dev50` 或择时分 < `double_timing`）且距上次卖出 ≥ `profit_interval` 天 且 stage=0 | 卖 `profit_fraction` |
| M-55 破位减仓 | 核心仓 | `consec_below200` ≥ `below_days[tier]`（标准层另含“趋势破位”红线或择时连续弱，进攻层另含择时连续弱），stage<2，持有 ≥ `minimum_age`，非恐慌 | 卖 `broken_fraction[tier]`，只执行一次 |
| M-56 警戒减仓 | **仅标准层** | 质量分 < `normal_alert_quality` 或成长分 < `normal_alert_growth`（状态版本新于建仓版本）且 dev50 < 0，stage=0 | 卖 `normal_alert_fraction` |

clamp(v, [k, 下限, 上限]) = min(上限, max(下限, k×v))。止盈价位 = 50 日线 × (1 + 阈值/100)。
