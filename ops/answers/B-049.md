# B-049 提交前自验清单（需求方验收逐项照此复核）

> status“已完成”条目逐项写：编号｜通过/不通过｜测试名｜证据摘要。任一项做不到或冲突，先停下写清。一次性数据库按全部迁移建表，用继承 `role_perception` / `role_web` 的登录账号运行（不额外授权）；模型用计数客户端。

- **R1 `test_case_cadence`**：3 个 pool 异常、跨 25 个交易日的注入时钟：每个案例在 T+1/T+5/T+20 各有一条打标；故意让 T+5 上游缺数据 → 案例“未完成”且写明原因；打标只用当日可见数据（晚到行不参与）。
- **R2 `test_precursor_snapshot_daily`**：连续 3 个交易日，每日 59 只 + 全部篮子各一行；缺维度写原因；非交易日不写。
- **R3 `test_miss_sample_frame`**：抽样集合与“系统是否发现”无关（固定随机种子下，把系统发现标记全部翻转，抽到的集合不变）；检出率分母含未发现项；未知/数据不覆盖单列；确认漏检后该异常处置卡为 ⑤。
- **R4 模式库**：9 例不出现、10 例“观察”、30 例且保留样本成立“有效”、30 例但保留样本不成立仍“观察”；每组展示反例。
- **R5 `test_reports_contents`**：周报、月报包含 FR-M10-10 全部区块（区块名清单写在测试里）；影子 5/21/63 日统计与上游价格逐值相等。
- **R6 `test_oneliner_grounded`**：录音回答引用了当日异常 id → 采用；不引用 id 也不是“无异常” → 模板句；模型异常 → 模板句；每日调用计数 1；输入 payload 只含当日页面 JSON 事实（无其他日期数据）。
- **R7 `/review` 页面与 B-048 回归**：`/review` 返回五个区块；B-048 P1–P10 全部通过；市场与研究页面仍无交易字段。
- **R8 迁移与权限**：迁移只建七张表；`role_perception` 可写、`role_web` 只读；其他角色无权限；没有新角色。
- **R9 调度与回归**：上游未就绪等待到期限后写 `skipped_upstream:`；成功以 job_runs 为准；`make phase1-test`、准确 head CI 通过；diff 不含上游算法与合同改动。

## 需求方复核方式

准确 head 上运行 R1–R9；合并后由 A 在生产应用迁移（需用户确认迁移）并部署调度，需求方核对首日先兆快照与案例。
